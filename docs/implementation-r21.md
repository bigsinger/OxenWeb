# R21：只保留当前发布及使用说明

日期：2026-11-10。当前应用版本0.1.0。用户明确确认“所有已发布版本都移除，只保留最新版”；本轮在Web/BFF实施，不修改官方Oxen 0.67.0、内核或固定OpenAPI。

## 当前发布规则

|对象|行为|
|---|---|
|已发布Release|每项目至多一个，发布新版自动替换旧版；移除旧记录、文件和分享链接，不提供历史列表或历史下载|
|自动Release Notes|在替换前计算并固定当前发布作为基线；保留新增/修改/删除、标注、附件、字段、README和提交摘要及可编辑说明|
|并发候选|另一候选先发布后，旧候选发布返回409 `RELEASE_BASELINE_CHANGED`；保留说明，重新检查、保存、打包后再发布|
|候选和内部快照|当前格式未发布候选与内部工作快照保持独立；不属于历史正式交付。快照不开放分享、不包含私人未提交草稿|
|撤回|撤销当前发布的下载并移除记录和产物，随后暂无当前发布；再次交付从源提交创建新候选|
|数据版本|Oxen分支/提交历史和私人草稿保持独立，删除旧发布不删除源样本或提交|
|退休逻辑|无预发布、手动设latest、发布模板、项目视图或分层发布；旧端点404，旧请求参数400|

发布仍是完整数据集ZIP＋manifest。业务字段不筛除条目，字段“是否导出”继续生效；导出定义、标签、附件、README及checksums保留。Skill压缩包是惰性数据，不展开执行。

先在原子控制写入中撤销旧记录/分享并持久记录清理任务，再仅删除经边界校验的UUID资产文件。缺失权限、未知文件、符号链接/NTFS junction等不能被递归跟随；发生异常时保持旧下载不可读并显示清理待核查，不将部分清理冒充完成。启动会继续既有清理任务。

移除旧发布模式兼容读取。独立的累计曝光摘要及通用源访问标记属于安全控制，不是历史发布；缺失或代次不匹配保守拒绝。标记初始化工具只能离线执行，不读取退休视图配置，不覆盖已有保护。见[后台保留机制](r21-release-retention-backend.md)、[源保护与恢复](r21-source-protection-and-recovery.md)。
