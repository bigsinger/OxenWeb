# R3 分层标签、项目目录与私有草稿

日期：2026-11-08。基于用户明确确认的[R3设计](proposals/label-layers-r3.md)，在既有数据管理与协作版本上整体交付。所有修改位于 TypeScript Web/BFF；没有修改官方 Oxen 0.67 server 或内核。SaaS 事实沿用冻结的[登录后快照](saas-logged-in-snapshot.md)，本轮新增标签、权限、目录及草稿属于本地扩展。

后续变更：用户在[R4](implementation-r4.md)明确取消开发期旧标签兼容要求，现已清理当前旧标签数据流和兼容入口。本文保留R3当时事实；当前实现与验证以R4为准。

## 功能与数据语义

- 全局标签管理使用独立组织、领域筛选，分为数据集模板、样本模板两类目录；另存组织预设、发布不可变版本、维度/选项释义、指定维护者与缺项反馈保留。
- 新预设包括两个数据集模板、通用样本质量及敏感信息、注入、Skill、行为偏移四专题。默认展示约4–6项，补充字段展开。旧累计式预设与旧发布 checksum 不改写。
- 分支绑定升级为V2：dataset/sample各自固定发布快照，支持一次CAS采用两层。旧V1及没有治理绑定的旧列定义进入显式兼容层。相同ID不自动解释为相同含义；首次采用新层不会将旧值自动提升。兼容同组织/同模板版本升级，仅保留经逐维度语义、类型、稳定选项和数值校验的意见。
- 项目标题、概览显示当前读取版本的数据集分类；编辑面板仅赋值，不管理字段定义。`dataset.assign` 独立控制赋值：实例管理员、项目管理员、负责人默认拥有；编辑、标注、复核人员默认没有，指定协作者可单独授权。组织规范维护权不授予私有项目读取或赋值权。
- 数据集标签是一份分支生效结果，记录操作者和版本；分支继承后独立变化。样本和文件意见仍按身份保存，自己的空值不会默认显示他人结论。参考意见只读，显式复制后才成为自己的草稿。旧同目标意见覆盖前归档，不删除历史值；完整检索可使用 `legacy.*` 命名空间。
- 样本任务行级能力在页面禁用越界操作；服务端保存、草稿预览和提交再次校验。现代样本复核语义 hash 与目录分类分开，完整绑定 hash 另外保留审计。正文、实际附件字节、文件标签、样本规范等依据改变仍使复核过期。旧证据保守读取，不改写证明。

## 保存习惯

分支是版本线；Oxen工作区是以分支提交为基础的未提交文件空间。数据编辑采用独立 Web/BFF 私有草稿，不要求用户手动创建原生工作区。

操作顺序：编辑多项 → 保存本机草稿 → 核对全部变更及前后值 → 一次提交到分支。保存只写本机磁盘，不创建上游workspace、不推进分支、不产生commit。按身份、项目、分支、基础提交隔离，刷新/重启可恢复；其他身份看不到草稿。草稿ID及revision双CAS防多页覆盖和删除重建的ABA问题，提交还检查expectedCommit、权限、任务范围、规范和内容。失败保留草稿，不静默rebase。正式提交通过既有DatasetService一次写入本机Oxen服务目标分支；没有伪造必需的第二次push。

分支标签面板和数据编辑消费同一私有草稿。面板明确提示一次提交包含此身份本分支的全部已保存修改，跨样本内容需先展开完整diff核对。离开前的未保存输入保护继续保留；未登录公开访客直接读取公开版本，不访问私有草稿接口。

## 项目目录与表格

默认按最近添加或修改时间倒序。BFF读取所有分支真实head对应提交时间，不信任可能过期的仓库摘要时间；自己的本机草稿时间单独标识。无有效时间置后，命名空间/名称稳定排序。目录标签和样本数仍取配置的默认分支固定head，不随排序来源切换。

领域、研究主题、用途、来源支持结构化筛选；同维OR、跨维AND，再与关键词、组织和可见性结合。候选、计数、摘要均先验证读取权限。旧自由关键词只作补充检索，不冒充结构化维度。卡片最多3标签和+N；样本数位于总大小前。未配置、未填写、有分歧、暂不可用分开显示。

全局 `#app table th/td` 为middle，保留水平文字/数字对齐和代码正文布局；各类表格共享该规则。

Release同时携带两层固定绑定、scope列和完整compatibility，人工值/源记录/证据分开。标准包再导入保留两层规范和兼容意见的来源快照，不将外部模板或原审核证明直接提升为本组织权限/审核通过；需显式采用本组织规范。
