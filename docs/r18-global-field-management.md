# R18 全局字段目录维护

日期：2026-11-09。此项是用户要求的 Web/BFF 扩展，未修改 Oxen 服务端、内核或固定 OpenAPI，也未重新调研或改写 SaaS 冻结观察。

## 行为与边界

| 事项 | 当前规则 |
| --- | --- |
| 字段目录 | 允许 0–200 个全局选择型字段，字段 ID 使用小写英文语义键；可新增、编辑显示名称/说明、改单选或多选、退出活动目录。ID 在编辑器中固定，更名通过新增字段完成。 |
| 预置四维 | 初始目录仍为 split、quality、purposes、visibility。管理员可以移除或修改类型/选项；已删除的字段不会自动补回。正式发布检查项目的固定提交：所需维度缺失、类型或取值规范不符合发布规则时会阻止发布，不能退回全量包；目录变更本身不会改写项目已采用定义或固定历史包。 |
| 选项 | 每个字段 1–200 项，可新增、编辑 ID/显示名/说明/颜色和移除；改选项 ID 相当于旧值退出、新值新增，不转换既有原值。 |
| 写入身份 | 仅有效的实例管理员可以保存全局目录、维护查看人员和批量同步项目。项目管理员或原先指定的字段维护人员没有全局写权限。原指定人员保留只读目录/历史/采用情况入口。 |
| 普通消费 | 已认证的有效人员仍可读取供项目表单消费的当前目录；是否能读取某项目和样本由该项目权限另行决定。目录查看权限不授予样本访问。 |
| 保存 | expectedRevision 比较后生成新版本，保存完整不可变目录快照和宏观审计；无自动回写项目。目录保存不接触样本文件。 |
| 项目采用 | 新项目采用当前活动目录；现有项目显式同步，按每个项目的固定提交、权限、任务/草稿及现有数据约束校验，产生单次定义提交。保留展示、导出、排序与历史列宽信息。 |
| 来源 | 每个已采用字段保存 globalField.id/revision。任一全局字段的采用都会建立项目的持续治理标记，恢复旧版本或移除目录项不能解除标记。旧四维快照继续识别。 |
| 活动字段 | 项目中不允许本地改释义、规则、选项或删除；可以单独勾选展示和导出并调整顺序。可以保留已采用的固定旧版本，或明确采用当前目录。 |
| 已退出字段 | 目录移除后，现有项目的定义快照、字段原值和历史均保留；采用情况和项目设置明确标记“已退出全局，项目保留”。同步不会删除。项目负责人可通过既有字段删除流程输入准确 ID 确认、校验权限和任务/草稿后创建新提交；旧提交仍可读取。不能用“移除配置”悄悄抹去来源。 |
| 不兼容同步 | 比如已有 urgent 值而目录移除 urgent，或已有文本但新定义变多选；同步返回 DATASET_FIELD_CONFLICTS，目标 HEAD、样本字节和旧定义不变。管理员必须先规划合法的数据变更，系统不自动映射。 |
| 容量 | 单目录上限 2MiB；控制面历史累计接近 28MiB 时停止新保存并提示扩容，不裁剪旧版本，避免超过现有 32MiB 读取门限。 |

全局字段 ID 拒绝身份、源真值和对象保留名称，例如 id、uid、label、ground_truth、constructor；不能用一个选择型全局字段覆盖这些语义。既有数据字段与新全局 ID 冲突时，同步仍需要通过现有数据约束校验，不静默改值。

## 界面

- 全局“字段管理”：活动字段目录、管理员新增/移除、选择类型、选项维护、明确保存；目录为空时显示真实空状态。删除和类型变化有影响说明，保存为新目录版本。
- “目录历史”：先读取轻量版本列表，按需读取完整只读快照，查看不执行恢复。
- “字段目录查看人员”：只授予页面读取，界面与服务同时禁止指定人员写入。
- “项目采用情况”：显示活动规则待同步项，以及已退出而保留在项目中的字段；分别显示更新、当前、冲突，不把上游失败计为同步成功。
- 旧本机表单基线不同时仍保留输入，可明确恢复至表单后核对保存；异步返回按身份/代次隔离，保存进行中不允许导航，防止覆盖新身份状态。

## 本地扩展 API

| 端点 | 权限 / 含义 |
| --- | --- |
| GET /api/global-fields | 管理目录查看权限；返回 canManage（页面可见）、canEdit（管理员写）与当前目录。 |
| GET /api/global-fields/catalog | 沿用已认证人员的消费读取权限。 |
| PUT /api/global-fields | 实例管理员，expectedRevision CAS，保存新完整版本。 |
| GET /api/global-fields/history | 管理目录查看权限；仅版本、时间、操作者及字段数量。 |
| GET /api/global-fields/history/:revision | 管理目录查看权限；完整只读历史快照。 |
| POST /api/global-fields/maintainers | 实例管理员，维护目录只读人员，保留旧路由名以免混淆已有审计记录。 |
| POST /api/global-fields/synchronize | 实例管理员；按目标提交和项目权限分别显式同步活动定义。 |
| GET /api/repos/:namespace/:repo/dataset/fields/global | 项目读取权限，包含 missing/changed/retired，不写入。 |
