# R20：完整数据集发布界面

日期：2026-11-10，Asia/Shanghai。依据用户最新确认，完整移除全局发布模板、项目视图及分层发布界面，改为一次发布整份已提交数据集。这是本地 Web/BFF 扩展；没有新增 SaaS 观察，也没有修改 Oxen 内核或真实样本内容。R19 文档保留历史事实，不再代表活动界面。

## 使用流程

| 操作 | 行为 |
|---|---|
| 创建 Release | 填写版本号、来源分支／提交、标题；可选择预发布。保留空值 Tab 建议 |
| 自动说明 | 后端按固定提交与上一可比正式版本生成确定性的变更说明。表单自动填入，可继续编辑；没有模型请求或样本正文外发 |
| 核对变更 | 显示样本数、关联附件、导出字段、比较基线及样本和文件的新增／修改／删除。首个完整数据集版本明确标为首次发布 |
| 保存发布候选 | 同时提交预览的提交 ID、基线版本 ID（含首次发布的 `null`）和计划摘要，防止预览后基线或内容变化 |
| 校验打包 → 核对发布 | 保留原有异步操作、失败提示、草稿保护和版本修订检查；发布后说明与资产固定。最新稳定版仍需显式指定 |
| 导出工作快照 | 直接打包选定分支已提交的完整数据集，按字段“是否导出”配置；没有视图选择，不包含未提交草稿 |
| 下载与分享 | 下载固定资产；只有后端明确 `audience=shared`、`shareable=true` 的资产可创建外链，链接可过期或撤销 |

“完整”指当前逻辑数据集在该次提交的全部样本，保留项目字段导出配置。`split`、`quality`、`purposes`、`visibility` 等普通业务字段继续可编辑和导出，但不再决定发布分组。不要把业务字段取值当成发布权限或样本级 ACL。

## 自动说明与手动编辑

自动生成的原文保存在独立 `generatedNotes` 元数据中。编辑后的 `notes` 是最终发布说明：数据包不重复拼接两份说明。若更改来源或重新检查，尚未修改的自动文本随比较结果更新；已手工修改的说明继续保留，并提示可以显式重新采用自动说明。409 时保留版本、标题和说明，重新检查后再保存。

比较基线由后端选择最近的、已发布、非预发布且未撤回的 `dataset-v1` 正式版本；旧 R19 分层产物不能当作完整数据集比较基线。存在旧记录但尚无完整发布时，显示首次完整发布及后端解释。保存后的基线不在打包或发布时偷偷变化。

## 移除范围及保留边界

已删除 `PublishingTemplatesView`、`DatasetViewsPanel`、`HoldoutImportPanel`、`ReleaseConfigurationFields`、`ReleasePlanSummary`，以及旧发布 UI、对话框、隐藏导入辅助代码及专属样式。全局导航、路由、项目页签、权限探测和新建项目提示不再涉及发布模板或视图。R19 专属 UI 测试随退役代码删除。

工作台中专门的“发布分组”入口、批量设置、筛选、编辑组件及 `dataset-evaluation-ui` 写入逻辑删除。历史家族信息仅作只读列和证据展示，不影响发布范围。普通源字段、人工标签、字符片段、步骤、源样本 CRUD、列布局、草稿和统一提交机制保持原功能路径。旧待恢复分组输入不能应用，原始输入仍可保留对照，避免静默丢失。

R19 的 `1.1` 记录只读，不提供编辑、重建、新建分享或旧配置操作；已有固定资产和已有分享链接继续遵循后端原权限，可查看或撤销。更早且后端标为 `legacy` 的记录仅保留审计。前端不按文件扩展名、位置或历史版本号推断下载权限。

## 代码与接口映射

| 文件 | 作用 |
|---|---|
| `components/ReleasesPanel.vue` | 简洁表单、自动说明、固定候选、打包发布、快照、资产、勘误与分享 |
| `release-ui.ts` | 自动文本更新保留人工输入、版本可变性、明确分享授权及显式最新稳定版 |
| `release-dialog.ts` | 对话框焦点边界及键盘可用性 |
| `components/releases.css` | 共享 tokens、窄屏表单、内容换行及比较统计 |
| `components/DatasetOverview.vue` | 只展示显式指定的已发布稳定版，不用任意候选补位 |
| `components/DatasetWorkbench.vue` | 移除独立发布分组操作；源编辑及人工标注保持独立 |

前端使用既有 `/repos/:namespace/:repo/releases` 和 `/snapshots`。新增简洁预览为 `POST /releases/preview {sourceRef, prerelease}`，不发送模板、视图或分层参数。创建／更新发送 `expectedCommit`、`expectedBaselineReleaseId`、`expectedPlanDigest`；更新另带 `expectedRevision`。当前发布版本标识为 `dataset-v1`。
