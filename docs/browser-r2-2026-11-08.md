## 必须保留的未通过项

本次浏览器真实点击快照 ZIP 下载时，自动审批未授予 `http://127.0.0.1:5173` 文件下载权限，工具拒绝执行。未绕过、未换浏览器/底层命令实现同一下载，因此“浏览器实际落盘下载”**未通过**。构建清单出现不能替代该项。独立真实服务验收脚本对另一个合成发布包完成 API 传输和 SHA/往返校验，结果见 [官方联调记录](r2-live-acceptance-2026-11-08.md)，不能代替浏览器下载权限。

分享地址需实际可达部署；本版保持本机回环运行，不自动开放公网或向他人发送链接。API 的到期、撤销和权限测试不等于跨设备下载已验证。
