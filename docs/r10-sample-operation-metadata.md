# R10 样本操作信息、字段颜色与完整列展示

日期：2026-11-08。范围是本地 Web/BFF 扩展，不修改 Oxen server、内核、固定 OpenAPI 或原样本字段。与运行稳定性包一起集成；浏览器与正式服务验收由主任务记录，本文不把静态实现或专项测试冒充界面通过。

## 操作信息的语义

数据编辑表格独立显示“最后修改时间”和“最后操作人”，均标记为“系统记录 · 不导出”。系统查询键为 `system.updated_at`、`system.actor`。源记录即使已有 `updated_at`、`actor` 等字段也保持原值，用 `data.updated_at` 等明确查询；系统信息不通过增加源样本列实现。

时间表示该固定分支/提交中已提交的内容修改或样本级人工标注（含片段/步骤）操作。首次手动创建、初始化导入及后续追加导入记录导入者与时间。项目分类、README、模板展示配置、反馈、复核和合并属于其他层级的操作，不伪装为每条样本的内容修改。私有草稿及原始控件检查点不会更新已提交操作信息；新样本提交前显示“待首次提交”。

时间来自以下可验证证据：

1. 新初始化数据集在 `.oxenweb/dataset/activity.json` 记录规范源文件 SHA、首次导入时间与实际 BFF actor。
2. 后续内容/追加操作使用原有每条样本独立覆盖文件中的 `actor`、`updatedAt`，补充 `createdAt`；样本标签使用原有每条样本/操作者记录的时间和 actor。读取时按时间合成，不在正常编辑路径更新一个全表共享文件，避免不同条目分支因操作时间而出现额外合并冲突。
3. 旧数据优先采用固定提交中规范源文件的 Oxen 存储时间；旧 provider 未返回文件时间时，只在最多16个近期提交中查找该规范路径确实新增/修改的记录。**这是文件级证据**，界面明确标“源文件时间”，不声称它是精确逐样本历史，也不把提交中的通用作者误认成实际标注人员。
4. 无法验证时显示“暂无记录／未知”，不使用当前时间、仓库最后更新或 README 更新时间猜测。历史页面读取历史证据，不继承后来分支的操作人。

时间按浏览器本地时区显示，悬停可核对原始时间、来源、创建/导入时间与未提交说明。用户可以点击系统表头对完整匹配结果排序，也可在条件筛选选择系统时间并用本地时间控件设置前后界限；时间过滤、排序均发生在分页之前。空时间保持最后，操作人支持现有等值/包含/未填写过滤。

## 导出边界

系统元数据位于 `DatasetSnapshot.rowActivity`，不混入 `rows` 或源字段。现有 Release/工作快照以显式样本格式导出，不加入该映射或 `activity.json`。新增的系统操作人和时间不进入 `samples.jsonl`，也不加入 CSV/JSONL 源记录或附件。

源文件原本自带的同名时间/人员字段必须保留。已有人工意见、复核证据、来源与版本包审计信息仍按原导出格式保存；不因隐藏这两列而删除既有标注证据。原始来源 ZIP 也不重写或解包执行。

## 字段选项颜色

字段设置的单选和多选选项新增颜色选择器。每次加入选项从共享调色算法选择尚未使用的颜色，允许手动选择；旧选项未配置颜色也有稳定默认色。表格单选文字、多选独立选项采用该颜色，原始类型和值不转换。

颜色保存在字段展示元数据 `optionColors`。键使用 `JSON.stringify([typeof value,value])`，区分布尔 `false`、数字 `0`、字符串 `"0"`。服务端只接受 `#RRGGBB` 且键必须对应当前选项，禁止将 CSS 或其他选项的颜色混入配置。最多200项，与既有选项上限一致。

颜色与顺序、列宽一样，从校验、私有草稿和复核的语义指纹剥离。修改颜色不修改源数据，不使既有复核失效；私有草稿同步到新展示提交仍要求明确操作与 CAS。修改枚举内容或类型仍属于规则变更，不因存在颜色而绕过约束。

## 完整展示与交互细节

用户本轮要求取代 R9 的首次六列限制：**所有源字段与已配置字段均默认显示，包括附件引用、长字段及只有列宽、顺序或颜色的配置**。旧个人检查点首次恢复补足完整列，并记录已见过的源/配置字段；之后用户主动隐藏可继续保留，新字段再次自动加入。列面板提供“显示全部字段”、显示数量和已有别名。源列仍采用项目保存顺序，系统列独立展示。不为减少横向滚动而截断字段，宽度继续由固定像素/权重配置控制。

工作台的私有草稿、原始输入保留、正式提交与复核词义分开，绿色明确只表示提交成功。分支/固定 hash/历史只读共用上下文说明；源列排序明确使用 `data.` 命名空间，避免源字段和系统字段同名时混淆。

标签表单展示适用层级、已填写数量、稳定维度 ID、当前选项解释及折叠部分的已填写数量。未填写、不确定、不适用保持不同含义，不添加自动判定或新标签维度。

批量操作保留既有选择语义，明确显示已选与当前页条数；筛选或翻页不暗示自动选择所有匹配记录。批量面板列出实际有权处理的稳定身份与排除数量，按钮使用同一候选集合计数，不能把已删条目或无权限条目一起写入。非法 JSON 提示就近中文修复说明并保留原文。
