## 实际页面验证

开发环境 5173 完成下表检查，构建后在 3001 重启并复核文件、查询、标注与管理页面。未将类型检查当成浏览器验证。

| 检查 | 可见结果 |
| --- | --- |
| 未带路径直接打开查询 | 提供真实目录选文件；选中真实 benchmark 后显示2,000行/14字段，不再默认其他项目的数据路径 |
| 全表规则统计 | `统计 label 等于 1` 扫描2,000/2,000行，返回1,000；本轮没有调用外部模型 |
| 条目跨页 | 详情由样本50进入样本51，背景表格进入下一页；关闭后返回表格 |
| 文件/分支上下文 | 表格→查询/编辑/标注携带文件；切换 ui-source 仍保留 sample.jsonl，载入对应版本 |
| 提交深链接 | 点击哈希进入指定提交，刷新保留详情；父提交、浏览器返回、返回历史正常；详情可见5文件与CSV/JSONL结构化新增行 |
| 未保存数据 | 合成记录只加入本地草稿；离开提示，取消保留草稿，放弃后离开；没有把该草稿提交到仓库 |
| 标注与媒体 | 合成样本展示原字段、关联 alpine.png 与独立标签栏；三级作用范围与列配置入口可见。正式版新建“验收状态”单选列（待审/通过/需修改），为test-1选“通过”并提交，刷新回读仍为“通过” |
| 协作页面 | 分支3条；MR空待合并状态、已合并请求、保留的2文件比较和1条讨论可读；未新建/合并MR |
| 工作区意图 | 文件管理→上传，进入 main 分支工作区，显示目标目录/工作区及暂存提交顺序；本轮未触发上传文件选择器 |
| 设置 | 常规设置与用户/协作者导航切换、URL section同步；未修改成员、可见性或默认分支 |
| 390×844窄屏 | 首页、项目切换菜单、表格、查询可用；表格自身横向滚动，文档无横向溢出；检查后恢复默认viewport |
| 筛选与键盘 | 私有范围→公开项目→返回首页，范围重置为all；弹层内按 / 或Ctrl K不移到后台搜索 |
| PDF与控制台 | PDF.js显示1/1页与实际正文；开发浏览器无warn/error日志 |

本轮还修复了工作区异步文件读取的过期响应：关闭或切换仓库/工作区/路径后，旧响应不再覆盖新编辑器。历史标签识别兼容短十六进制提交ID；真实同名分支以已加载分支表为准。

本轮唯一持久化页面写入发生在本机合成项目 `local/saas-ui-check-1794095882937`：标签列提交 `cc42649fa87d502fd65c5c03e3f90139`，样本标签提交 `71be87e0c1da81c1bf4340e239f15abf`。源记录、真实benchmark和SaaS云项目没有被此次界面验证修改。

## 构建、测试与运行

- `npm run build`：Vue/服务端 TypeScript、Vite 与 BFF 构建通过。存在两项非阻塞的静态/动态混合导入提示（FilePreview、LabelManager），不影响功能。
- `npm test`：本轮70项总计，63通过、0失败、7项真实服务测试默认跳过；未把跳过计为通过。本轮主要为前端调整，既有真实写入回归记录见历史验证文档。
- 官方 Oxen 0.67.0：`127.0.0.1:3002` 健康；生产 BFF/静态页面：`127.0.0.1:3001`。临时Vite进程已停止。
- 知识库结构索引校验：11个页面的证据路径与组件路径全部存在。
