## 新增样本与管理需求

| 用户需求 | 实现语义 |
| --- | --- |
| 最后修改时间 | 表格“最后修改时间／系统记录·不导出”。新导入和后续已提交的内容/标签操作记录真实actor/time；私有草稿不冒充已提交。历史优先固定版本的可靠样本/源文件证据，无证据显示未知，粗粒度源文件时间会明确标注 |
| 时间排序、筛选和批次识别 | 使用独立系统列ID，全表排序/时间筛选后再分页；不与原样本中同名字段混淆。批次初始导入时间保留为创建证据，后续修改时间更新 |
| 最后操作人 | 表格显示稳定身份对应名称，历史无法确认时为未知；不会把通用Git作者或当前登录人推断成每条样本操作人 |
| 导出排除系统信息 | 活动信息是BFF版本化扩展，既有源记录的同名字段仍保留；系统 `updatedAt/actor` 不混入JSONL/CSV或Release样本。独立人工意见/审核证据继续沿用既有导出语义 |
| 单/多选颜色 | 新选项分配不同默认色，可用颜色控件修改。颜色按JSON标量类型+值匹配；只允许有效HEX与已配置选项；单选文字、多选chip使用配置色。纯颜色不改变类型约束或审核指纹 |
| 完整列 | 初次进入及旧检查点恢复补齐所有源/配置字段，取消旧六列限制；之后个人明确隐藏可保留，提供“显示全部字段”。字段顺序沿用项目配置，宽表保持滚动，不截断字段 |
| 宏观全局日志 | 顶部“操作日志”，仅实例管理员/授权审计人员；项目生命周期、发布、治理配置、成员、权限和令牌变动等元数据，90天保留；筛选、分页与空状态完整，不补造过去事件、不存正文/token/原始问题 |
| 发放和管理令牌 | 顶部“访问管理”创建指定项目或实例角色凭据，带有效期；账号“我的访问令牌”查看本人/本人发放的摘要、状态和权限，轮换/撤销。原始令牌只展示一次、持久化只存hash，不提供查看/复制别人明文的功能 |

详细来源与导出边界见 [样本系统信息与颜色](r10-sample-operation-metadata.md)。授权、失效、恢复和接口矩阵见 [身份与日志](access-and-audit-r10.md)。
