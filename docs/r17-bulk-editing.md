# R17 批量样本编辑

2026-11-09，本地 Web/BFF 扩展，不修改 Oxen 服务端或内核。入口为数据编辑中选中样本后的“批量编辑”。它复用私有草稿和显式统一提交，不逐条自动提交。

|目标|修改方式|含义|
|---|---|---|
|单选、布尔、文本、数字及已配置字段|统一设置取值|复用字段的类型、枚举及校验；只更改当前字段|
|多选／基本值数组|增加、移除、替换全部、清空列表|增加保留其他选项且按原始类型去重；移除不会给缺失／null 的样本凭空增加空值|
|可为空／可缺失的样本字段|设为 null、移除值|两种状态分开显示；必填或不允许 null 的配置继续生效|
|本人的人工单选／文本标签|设置、清空我的取值|清空用显式 null 撤去本人的该维度，不覆盖别人的意见|
|本人的人工多选标签|增加、移除、替换、清空|保留未选择维度、既有片段／步骤标注；弃用选项不能给新样本增加|

身份、来源证据和既有原始真值受保护，不提供批量入口。批量编辑四维值同样是内容修改，提交后可能使之前的复核证明失效；`gold` 不能代替独立复核，`visibility` 不授予访问权限。

操作顺序为：选择稳定样本身份 → 指定字段和方式 → 预览将修改／未改变／无权限跳过数量及完整身份范围 → 勾选核对 → 加入草稿 → 继续修改或保存私有草稿 → 核对差异并统一提交。列表最多选择500条；无法读取的已选身份会阻止整批预览，不能静默缩为当前页。跨页读取固定提交并核对私有草稿版本。

原始批量输入存于已有工作台检查点的 `sourceBulk`，保留未完成或格式错误的文本。恢复继续核对身份、项目、分支、基点、字段规范、私有草稿版本及正文／标注各自权限；不会从检查点获得新的编辑权限。真实字段采用脚本也把未提交的批量输入计入预检，避免误当成仅浏览状态。

实现为 `DatasetBulkEditor.vue`、`dataset-bulk-editing.ts`，由工作台统一维护选中行读取、私有草稿及提交。新增针对性回归涵盖精确范围、权限排除、类型化集合运算、缺失值移除不变、源保护、非法枚举、原始CAS、已有新增样本与其他意见／片段保留，以及原始输入恢复。实际命令和浏览器／原生验收以 R17 总体验收记录为准。

原生联调脚本 `scripts/r17-grid-acceptance.ts` 默认只打印计划；执行模式只使用既有3条合成项目 `local/r16-synthetic-fields-mw94rjov`，不会创建账户、模板、项目或操作四个真实数据集。脚本需在新版部署后由主线程显式运行，不能把脚本编写完成视为原生验收通过。
