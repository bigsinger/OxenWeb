# R12 发布分组与分层交付界面

日期：2026-11-09（Asia/Shanghai）。用户已确认算法与 QA 只下载发布包；本轮采用“一份私有受限主库＋明确管理分组＋固定版本四视图”。这是本地 TypeScript Web / BFF 扩展，不是新增的 SaaS 原生事实，也不修改 Oxen 内核。

## 界面与操作顺序

复用冻结知识库 UI04/05/06/11 的表格、覆盖详情、明确草稿/提交与设置侧导航，以及既有 Releases 候选→构建→核对发布顺序；没有再次访问云端。

项目设置的“发布分组”仅对同时拥有 `release.manage`、`data.edit` 的身份显示。初始不开启。负责人必须先使用私有项目，再勾选“消费者只下载包、旧全量分享失效、安全模式不可关闭”的确认，并在第二次确认中明确启用。启用中的页面切换和刷新受保护。普通标注/复核人员没有此设置入口；服务端继续校验实际能力。

数据编辑启用后增加三列 `evaluation.visibility`（使用范围）、`evaluation.suites`（评测用途）、`evaluation.family_id`（样本家族）。管理列与源字段、系统操作时间、人工风险标签独立。列头可按全表排序，条件筛选提供范围/用途选项及未填写状态；原源字段展示、别名、14px 字号与垂直居中保持。

负责人可通过覆盖详情直接设置单条分组，也可勾选多行→“设置发布分组”→逐项选择要改的管理字段→核对稳定身份与范围预览→加入草稿。没有勾选的字段保持原值；明确清空和保持原值不同。随后沿用“保存私有草稿→查看变更→填写说明→提交到分支”，不会每次选择生成一次提交。负责人拥有分组选择能力不会因此得到普通样本标签赋值权限。

未设置范围仍显示“未设置”，不默认共享。页内已知家族跨共享/隐藏会就近报错；BFF 保存/提交对全量固定数据、既往共享记录与附件作权威校验。分组不会变成源字段或伪造专家裁定，勾选金标不会授予复核通过状态。新样本可以在同一私有草稿里新增并设置分组；删除/撤销新增也清理该身份的分组操作，保留其他条目。

分组操作同样红色表示尚未提交，成功提交后本轮绿色，刷新或离开重进清除绿色。状态按 `baseEvaluationRows` 的真实已提交基线比较，不按操作存在与否着色；批量设置相同值不会标红，成功后的绿色仅取服务端真实差异中的改变身份。保存后的草稿查询投影不替代基线，改回原值会清除红色。原始输入检查点保留批量面板的未完成选择，范围/用途筛选构建器采用同步默认值初始化，恢复已保存的 `holdout` / `regression` 不会被异步默认值覆盖；并要求同一身份、项目、分支、基点、规范及管理权限才可恢复执行；权限撤销后保留只读对照，不自动执行。

## Releases 与资产边界

读取安全策略失败时，创建候选与分享采用拒绝执行的状态并提供重新核对。受限主库新候选使用 `deliveryMode=tiered`，禁止附带原始归档。候选仍由 BFF 固定于已提交版本，未保存或未提交的分组不包含在内。

负责人在构建前看到固定提交的真实四份视图预览：金标、回归、非隐藏全集、隐藏集的行数、附件数、导出源字段/排除字段，金标与回归实际交叠数，以及未设置/未完成独立复核的排除原因。没有预览、预览错误或阻止问题未解决时，不可构建。正式构建和发布仍由 BFF 重新核对独立复核与成员/附件边界。空视图显示 0 条，不宣称已经覆盖。

资产逐项展示 view、接收范围、大小和 SHA-256。共享 ZIP 包含 `gold.jsonl`、`regression.jsonl`、`nonhidden-all.jsonl` 及所选成员的附件和限定辅助信息；隐藏 ZIP 独立，仅负责人可见与下载。分享表单必须显式选择 `audience=shared`、`view=shared-bundle`、`shareable=true` 的 ZIP，提交明确 `assetId`，不依赖文件名或数组第一项。隐藏资产没有外链选项。启用受限主库后，旧标准完整 Release 的全量分享显示拒绝原因；后台也阻止旧令牌下载。

完整工作快照仍是可信主库成员内部交换入口，界面明确它不是算法/QA 的共享评测包。源字段“是否导出”继续只是正式发布列投影，不被用作行隐藏或主库读取权限。

## 文件映射

- `EvaluationPolicyPanel.vue`：私有主库策略、明确启用及状态/失败反馈；`SettingsPanel.vue` 接入独立板块。
- `EvaluationAssignmentFields.vue`：单条/批量分组控件；`dataset-evaluation-ui.ts`：名称、只改目标身份的队列合并、页级家族预览。
- `DatasetWorkbench.vue/.css`：管理列、筛选排序、选择权限、独立详情区、私有草稿/提交、会话高亮与批量范围确认；`dataset-workbench-checkpoint.ts` 保留与恢复权限保护。
- `dataset-cell-editing.ts`：删除样本时同步清理该身份的待提交分组。
- `ReleaseDeliverySummary.vue`、`release-delivery-ui.ts`：真实固定版本视图及显式可分享资产筛选；`ReleasesPanel.vue` 与 `releases.css` 集成。
- 尺寸与颜色继续使用 `style.css` 共享 tokens，新增三项管理列宽 tokens。
