# 四个真实项目的全局字段采用

`scripts/r16-adopt-real-fields.ts` 仅面向用户明确要求的四个 `local` 项目，在 `main` 分支采用已发布的全局字段定义。它不写入金标、回归、隐藏或训练划分成员，不修改 Oxen 内核，不修改 R14 候选分析文件。

| 固定目标 | 全量条目核对 | 既有 split 核对 |
| --- | ---: | --- |
| `benchmark-sensitive-data` | 2,000 | 保留全部原值和缺失状态 |
| `benchmark-prompt-injection` | 2,000 | train 1,600、dev 200、test 200，逐条哈希保持 |
| `benchmark-skills` | 1,000 | 保留全部原值和缺失状态 |
| `benchmark-behavior-drift` | 1,719 | 1,719 个 null 保持 |

默认执行只读计划：

```powershell
npx tsx scripts/r16-adopt-real-fields.ts
```

明确执行定义采用：

```powershell
npx tsx scripts/r16-adopt-real-fields.ts --execute
```

脚本从本机配置读鉴权，仅访问回环地址的 BFF。全量读取固定提交，每页最多 200 条；任何数量、分页、内容哈希、固定 HEAD、已有划分或目录版本冲突都会停止。执行模式重新读取并检查，不把旧计划盲套到新 HEAD。

| 门禁与回读 | 检查方式 |
| --- | --- |
| 未完成工作 | 只读检查四项目所有身份在 main 的私有样本草稿及未完成工作台/字段配置输入；活动任务阻止采用。BFF 在每次实际配置提交时继续校验权限、HEAD 和活动工作。 |
| 源记录与稳定身份 | 对 6,719 条有效记录、顺序、稳定 rowId 和内容哈希分别计算摘要；旧来源表的原始字节另算 SHA-256。摘要在采用前后必须完全一致。 |
| 标注与评测信息 | 人工标签、历史意见、旧评测映射、操作时间、附件关联、README 和模板绑定分别核对摘要，不因新增字段定义而转换。 |
| 配置变化 | 采用后配置必须精确等于“原配置＋全局四字段规则”，保留其他字段和各项目的排序、列宽、导出/展示复选状态。 |
| 提交与分支 | 每个有变化的项目只新增描述文件提交，直接继承先前 main；其他分支不变。已采用当前规则的目标保持原提交。 |
| 全局目录 | 只读取目录，采用使用目录 revision 和各项目 HEAD 的 CAS；全局字段定义及 revision 不改写。允许安全控制面记录该项目已受全局字段发布保护的持久标记。 |

每次运行将元数据、配置和摘要放在 Git 忽略的 `.data/r16-real-fields/run-…-plan` 或 `run-…-execute`，不保存样本正文、密钥或访问令牌。`before.json` 保存采用前配置与固定版本；`synchronization.json` 保存服务实际返回；成功时生成 `after.json`、`verification.json` 和 `latest.json`。未知结果保留操作 ID、失败阶段并停止，不自动重复提交；批量采用可能部分成功，须按实际回执和当前 HEAD 对账。
