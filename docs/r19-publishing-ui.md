# R19：1.1 发布方式界面与验证

日期：2026-11-10，Asia/Shanghai。依据用户提供的《数据集管理平台 1.1 增量改造方案》，这些界面与 BFF 接口均为本地扩展；没有新增 SaaS 观察，不把本地选择记录为 Oxen SaaS 原生事实。沿用[冻结交互目录](knowledge-base/oxen-saas/interaction-catalog.md)的项目导航、版本说明、状态与权限保护。

## 当前入口与交互

| 入口 | 当前行为 | 边界 |
|---|---|---|
| 全局「发布模板」 | 「视图模板」「发布模板」两个子页，系统预置只读；有权限人员可以新增、另存、修改和删除自定义模板 | 入口按后端 `canManage` 控制；系统模板不能覆盖或删除；已有项目实例及 Release 不随模板变化 |
| 项目「视图管理」 | 查看来源模板及其采用版本；独立修改实例、预览计数和前 10 条、重置为模板默认、从模板或空白新建、另存为模板 | 配置属于项目，预览读取当前分支；不增补样本归属列，不改写真实样本 |
| 已有项目尚无视图 | 显示明确空状态，项目维护者可以显式初始化四个默认视图 | 不自动初始化或迁移已有真实项目，不移动原有隐藏样本；仍可使用受权内部完整导出 |
| 物理隐藏视图 | 普通访问仅可获得允许公开的计数；管理员及获准人员可维护受控物理存储，查看数量、修订和哈希摘要 | 不显示原文，不提供原件下载，不展开或执行 ZIP；只有哈希清单进入发布产物 |
| 创建 Release | 默认 `tpl_standard_public`；保留版本号、标题、说明与 Tab 建议；选择格式和视图，临时调整导出策略；先预览再创建固定实例 | 使用实际实例定义；不会反向修改模板；物理视图强制 `hash_only` |
| 发布预览 | 显示各视图数量、虚拟集合去重总数、隐藏文件条目数量、导出字段及所有警告 | 模板字段名和值严格照方案匹配；缺字段、`gold`/`golden`、`purpose`/`purposes` 等差异只诊断，不做隐式映射 |
| 自定义发布模板 | 当前配置可另存为新模板；选中自定义模板后可显式覆盖该模板 | 系统模板不能覆盖；保留 CAS 版本校验 |
| 工作快照 | 已配置视图时显式选择一个虚拟视图；无视图的旧项目仅可信权限可完整内部导出 | 未提交草稿不进入快照；无物理隐藏原文选项；完整内部包不能外链 |
| 历史旧 Release | 保留说明、提交、状态和审计 | 旧发布方式停用；旧资产不提供下载、重建、分享或旧分组表单 |

系统默认实例 `golden`、`regression`、`public` 是虚拟视图，`holdout` 是独立物理视图。标准发布结果为三个数据 ZIP、一个隐藏哈希文本及一个总清单。不是四个数据 ZIP。

按附件要求，`public` 条件是 `visibility <> hidden AND status = active`，其中命中的 `internal` 样本可能交付；预览警告直接显示这些命中数，正式发布确认再次说明。这个条件不被悄悄替换成旧版 `shared/public` 分类逻辑。使用者必须按真实字段语义明确修改实例条件。所有虚拟视图仍由后端排除隐藏源记录。

## 物理隐藏文件导入

只有后端同时授予项目维护及隐藏权限时，物理视图出现文件导入入口。每批最多 100 个文件、合计 8 MiB；每个文件一个独立条目，JSONL 整文件计一项，页面明确区分文件条目与样本行。上传内容仅编码为 Base64，不读取 ZIP 成员，不发送本地文件名，不自动选择任何真实资料。

提交前获取物理索引修订，发送固定 `operationId` 和 `expectedRevision`。提交后若结果未知，保留本页文件选择及原操作标识，只允许查询已验证回执，不使用新标识自动重发。不能用目录计数增长推断成功；只有操作标识、条目 ID、数量和 `verified: true` 完全匹配才显示确认成功。离开或关闭窗口有未完成操作保护；页面刷新不会替代后端故障对账。

| 组件或辅助代码 | 主要职责 |
|---|---|

| `HoldoutImportPanel.vue` / `holdout-import-ui.ts` | 受控隐藏文件导入及结果未知对账，不执行输入内容 |
| `ReleasesPanel.vue` | 新模板配置、临时覆盖、预览 CAS、固定候选、物化发布、受控快照与资产分享 |
| `ReleaseConfigurationFields.vue` | 统一格式、视图选择和导出策略；取消视图同步删除无效覆盖项 |
| `ReleasePlanSummary.vue` | 新发布计划计数、字段、筛选说明和直接可见的警告 |
| `publishing-ui.ts` / `publishing-dialog.ts` | 无模板副作用的 DTO 拷贝、实例输入裁剪、分享权限选择、弹框键盘边界 |
| `styles/publishing.css` | 共享色彩 tokens、纵向居中表格、窄屏叠放及表格内横向滚动 |

页面使用 `/v1/view-templates`、`/v1/release-templates`、`/v1/datasets/:datasetId/splits`、`/v1/splits/:id` 及其 `preview`、`from-template`、`reset-to-template`、`save-as-template` 操作。数据集 ID 将 `namespace/repo` 整体编码一次。物理隐藏使用 `/v1/datasets/:datasetId/holdout`、`holdout/import`、`holdout/operations/:operationId`；发布预览使用 `datasets/:datasetId/releases/preview`。

发布创建与更新提交预览返回的 `expectedCommit`、`expectedViewsRevision`、`expectedPlanDigest`，检测数据、实例、模板或物理成员变化。409 时保留表单供重新预览，不覆盖别人修改。项目切换、分支切换、登录身份切换、路由离开和关闭页面保留既有草稿保护方式；输入、预览、异步加载按上下文和代次隔离。弹框限制焦点，关闭后恢复触发位置。

旧活动组件 `ReleaseDeliverySummary.vue`、`release-delivery-ui.ts` 和未启用的 `EvaluationPolicyPanel.vue` 已移除；源样本字段、标注、家族元数据、复核证据及 Sample CRUD 保留，新发布不消费旧分组规则。
