# 单版本验收矩阵

本轮范围更新：图片、音频、视频样本管理不纳入当前版，历史媒体检查保留为旧事实。当前验收补充[四类样本导入](benchmark-import-2026-11-08.md)、[模板设计](ai-safety-annotation-design.md)、[模板真实服务验证](benchmark-template-validation-2026-11-08.md)及[完整性审计](completion-audit-2026-11-08.md)。JSONL 源文件读取/专用导入/结构化差异上限已调整为64 MiB；下表旧25MB差异限制只适用于其他格式及原生diff响应。

基线为用户提供的《Oxen Web UI 自研方案（单版本一次交付 · TypeScript）》及本轮明确的 JSONL、标签、查询和协作要求。本项目把浏览、写入与协作集成在同一应用版本；以下限制和待确认项不是拆分上线阶段的安排。

“代码已实现”只表示可以在当前代码中找到对应执行路径，不自动表示浏览器、真实服务、目标部署或 SaaS 对照全部通过。本文件不替测试记录补填成功。运行环境、实际命令、退出结果和真实写入后的回读证据以[集成验证记录](integration-results.md)为准；实际页面、PDF 画布、关联图片、写入与窄屏检查见[浏览器验证](browser-verification.md)。

## 复核方法

1. 在同一个目标版本运行 `npm run generate:api`、`npm run typecheck`、`npm test` 和 `npm run build`，记录实际结果。生成命令应验证固定原始哈希，而非自动获取最新规范。
2. 真实服务用例按各测试文件要求显式启用；例如完整 CLI 链路使用 `OXEN_LIVE_TEST=true`，用户样本标签使用 `OXEN_LABEL_LIVE_TEST=true` 与 `OXEN_SAMPLE_FILE`。默认跳过不表示已通过；目标服务、CLI、配置和启动方法见[本地服务说明](../infra/oxen/README.md)。
3. 真实写入必须在专用测试仓库/分支/workspace 中执行。创建、上传、commit、合并与 Push 后回读实际文件和 commit ID；冲突时确认目标内容未被错误覆盖。
4. 浏览器走完列表→导入→末页/嵌套记录→媒体预览→历史/diff→分支→workspace→三级标签→JSONL 行列编辑→查询→设置/角色。切换分支/路径时旧响应不能覆盖新上下文；写入捕获实际 commit，冲突不能覆盖他人的新版本。
5. 验证未登录、错误/撤销 Token、viewer/editor/admin 越权、跨 Origin/Host、缺少写保护头、路径穿越、缺失 CLI/clone、remote 错配、命令超时和上传/代理上限。模型外发复选框默认关闭，未授权请求应返回 403；授权前不执行真实样本模型调用。
6. 取得可访问的 SaaS 账号后，以冻结日期的页面证据逐页核对信息结构、操作语义与空/错/加载状态。公开文档、演示夹具和独立视觉设计均不能代替这一步。

## 当前不能宣称完成的部分

2026-11-08 已完成应用内浏览器真实登录后核对，并实际创建私有合成项目、核对5个上传文件、编辑列并提交、执行SQL与自然语言筛选。原Chrome会话问题已解决。当前保留边界是SaaS非空分支比较自身错误、未执行原生权限/删除/重命名操作，以及双方明确不同的本地扩展/格式/容量边界，不能再写成未登录或未访问页面。

模型路径在用户明确允许发送结构和问题后已完成真实样本校验，记录正文始终留在本机。适用范围已锁定原方案数据管理与协作；登录后核对完成不等于所有原生云端操作均通过，最终按[登录后快照](saas-logged-in-snapshot.md)逐项判定。

最终测试数量、当前服务地址和本轮浏览器通过项由对应记录填写；未记录的页面或异常路径保持待验证，不能从静态类型检查、演示或另一条成功路径推定。
