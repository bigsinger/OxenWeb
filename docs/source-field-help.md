# 源字段显示名称与帮助

2026-11-08，用户要求的本地 Web 扩展。SaaS 冻结快照仅有字段名、类型与内容；本页别名及说明为本地实现，不据此新增云端观察结论。

样本详情同时显示原字段 ID、可用的显示名称、当前值的实际类型。鼠标悬停字段标题或帮助图标可看说明；帮助图标可用键盘聚焦。字段没有已定义别名时不补空占位，也不根据记录正文猜测行业字段的含义。源 ID、值和人工标签定义不变。

解释来源按以下优先顺序读取：数据集描述 `fields` 中对应原 ID 的明确配置 → 常见字段字典。明确的空字符串可关闭该字段的默认别名或帮助。源字段 ID 精确匹配，例如 `Title` 的显式定义不会覆盖 `title`；通用字典仅允许常见字段名大小写匹配，不对任意路径或后缀扩展猜测。

基础字典位于 `packages/shared/src/field-metadata.ts`，覆盖 `id`、`uid`、`title`、`name`、`description`、`text`、`content`、`prompt`、`messages`、`question`、`answer`、`input`、`output`、`instruction`、`context`、`source`、`language`、`url`、`label`、`labels` 和系统导入来源证据字段。源标签、源回答和人工标注结论分别解释；显示链接或提示词不会访问链接、执行样本或调用模型。

管理员的显式元数据结构（合成示例）：

```json
{
  "fields": {
    "title": {
      "displayName": "工单主题",
      "description": "此集合中的工单标题。"
    },
    "custom_code": {
      "displayName": "内部分类编码",
      "description": "以本数据集说明中的分类表为准。"
    }
  }
}
```

元数据属于数据集描述，和分支版本一起读取、导出；不从单条源记录里接受伪装的元数据对象，也不使用标签模板列名替代源字段解释。长正文及对象仅在展开字段时格式化显示，避免切换条目时为折叠字段重复格式化大对象。

渲染组件 `DatasetSampleFields.vue` 使用 Vue 文本插值，帮助内容为纯文本；它保留原字段的展开/收起交互。表格列表不负责加载这些帮助信息，也不因此触发重新查询。
