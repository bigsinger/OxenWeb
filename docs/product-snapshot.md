# 单版本功能快照与验收

需求基线为用户提供的《Oxen Web UI 自研方案（单版本一次交付 · TypeScript）》及随后明确的数据编辑、自定义标签、查询和权限要求。所有模块在同一版本中集成，不把只读界面作为单独上线版本。本文区分独立实现、实际证据及尚待确定的 SaaS 范围。

## 参考冻结

- 后端：官方 OpenAPI 0.67.0，原始文件 SHA256、下载记录和固定源码 commit 见 `contracts/source.json`。原件不改，normalized 契约包含 35 项有源码依据的修正。
- 本地运行：官方 CLI/server 0.67.0，下载来源和校验值见 `infra/oxen/release.json`。
- 工程模式：固定 CSGHub commit 的功能索引，见 `docs/csghub-reference.md`，独立编写代码。
- SaaS：2026-11-08 已通过应用内浏览器完成真实登录后核对，保存 23 组页面证据。私有合成项目实际覆盖仓库、JSONL、工作区列编辑/commit、SQL/自然语言筛选、四类预览、行详情、历史/结构化 diff、分支和只读权限设置。非空分支比较持续显示 SaaS 错误页，不能宣称其 MR 生命周期已实测。详情见[登录后快照](saas-logged-in-snapshot.md)。

## 当前真实数据与版本化模型

用户的真实 2,000 行、14 列 JSONL 已导入 `local/prompt-injection-bench/data/prompt_injection_bench.jsonl`，保留嵌套 meta、数组、bool、null 和长文本。分页末行与原始结构核对通过；规则查询完整扫描 2,000 行、统计 label=1 得到 1,000 条，不能再沿用“只取首 500 行”的旧描述。数据内容仅作为记录处理，不执行其中的提示或命令。

自定义标签配置及三级赋值保存为 `.oxenweb/labels.json`，生成真实 Oxen 提交，随版本继承并按分支隔离；dataset scope 指当前仓库。行使用平行于 rows 的稳定 rowIds。旧 sidecar 停止新写入，保留显式迁移与无法唯一匹配的原记录。具体模型、提交和真实测试证据见 [JSONL 与标签](labels-and-jsonl.md)。

描述/tags、默认 Web 分支、可见性与协作者策略保存在 `.oxenweb/repository.json`。BFF 实际执行访问、写入和管理权限，默认 Web 分支可改；这些不是对未公开上游 ACL 或 SaaS 组织账号接口的假调用。设置与权限细节见[架构](architecture.md)，实际角色验证由相应记录说明。

## 模型查询的证据边界

模型入口经本机 Codex 生成受约束的只读计划，数据在本机执行；只发送字段名、类型和用户问题，程序不发送数据集记录正文。允许外发的复选框默认 false，后端对未允许的模型请求返回 403。用户也可明确选择无需模型的本机规则查询，两种引擎不会暗中互相替代。

初次真实样本模型调用被自动审批拒绝后，用户已明确允许仅发送字段结构和查询问题；后续真实查询成功扫描2000行、匹配1000条label=1、返回15组攻击类型计数，记录正文没有外发。本轮证据见[追加验证](verification-update.md)。

## 待确认的 SaaS 范围

用户明确本次范围为原方案的数据管理与协作全套，云图像/音视频生成、模型微调和部署不纳入交付。全站51个功能族的公开清单继续保留为参考，验收只以确认的范围和真实页面证据判定。

登录后页面已实际核对，用户批准的本地替代实现和 SaaS 原生控制面仍须区分。版本化标签、BFF ACL、JSONL 编辑、独立 MR 协作及 Codex 计划不自动证明与云端原生任务、Text2SQL 和控制面完全一致。SaaS 非空分支比较错误、部分提交摘要错误及未操作的原生权限/重命名/删除均保留为明确边界；以本次快照冻结，不追随后续改版。
