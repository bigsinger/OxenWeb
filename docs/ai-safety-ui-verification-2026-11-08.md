# AI 安全模板与样本管理界面验证

2026-11-08。实现范围为文本/JSONL、四类安全样本、Skill ZIP、本地标注和原有数据管理协作；图片/音频/视频样本管理不计入本轮。设计依据、字段字典、导入与真实提交见 [AI安全知识库](knowledge-base/ai-safety/README.md)。

## 已观察的页面行为

| 检查 | 结果与边界 |
| --- | --- |
| 选择模板 | 六套累计式预设可搜索、预览、选择维度；展示类型、说明、选项与适用层级 |
| 首次应用 | 合成项目应用 AI 安全基础，单次真实提交添加15列；原有“验收状态”及值保留 |
| 叠加领域 | 在同项目叠加 Skill 模板，15维度复用、仅新增6列；没有重建旧字段或推断样本结论 |
| 自定义 | 将预设“审核备注”改名“复核备注”并填写说明，保存后保持语义键与原始数据；重复应用基础模板显示新增0列，当前提交ID不变，自定义名称保留 |
| 独立判定 | 合成 sample.jsonl 的 test-1 保存“已审核/良性”，切到test-2仍未赋值；真值原字段没有变化 |
| 三级标签 | 合成项目的数据集级保存“合成生成/安全评测”；切文件层级同列为空，另存文件级“审核中”，各层值独立 |
| 固定版本冲突 | 外部添加合成 ZIP 提交后，旧版本草稿保存返回版本冲突；原草稿保留，明确放弃后重读最新版本，未覆盖新提交 |
| 文件与条目切换 | 目录选择、分支、page/row/scope 路由同步及离开守卫已经接入；审核状态筛选在换文件时重置，显示“当前页”范围，不冒充全表标签查询 |
| Skill ZIP | 合成清单一条记录关联 safe-skill.zip；显示3成员、包SHA和固定commit，SKILL.md按纯文本展示；不执行或写出成员 |
| 实际 Skill 末页 | 真实 benchmark-skills 第20页载入样本951；下一页禁用，关联包显示12个成员，人工判定仍为空；没有保存或截取真实样本正文 |
| 大文件查询 | 行为漂移原始大JSONL及规范化文件超过旧25MB上限，实际规则统计扫描1,719/1,719行，返回1719；没有调用外部模型 |
| 窄屏 | 390px宽下模板使用原生下拉选择领域，字段预览可滚动，底部操作可达；document宽380，未横向溢出；检查后恢复默认viewport |
| PDF兼容 | 升级PDF.js后合成PDF显示1/1页与真实正文，canvas宽691/高895；该项是既有能力兼容检查，不扩张媒体样本范围 |

模板弹层使用Teleport避开父容器裁剪和导航层级，打开时焦点进入弹层、Tab限制在可见控件内、关闭后恢复。标签控件有明确label，多选作为独立group，不把首个选项误命名为整段说明。加载/错误/冲突与权限状态沿用真实接口。

## 不能计为通过的下载项

固定版本标签导出接口的格式、完整列/三级赋值、模板来源、读取权限、分支前移时的版本固定及无写入均已通过测试和真实服务核对。这些检查发生在浏览器下载动作之前。

浏览器自动审批拒绝了从localhost站点实际下载标注快照，理由是没有授予下载权限；该动作已停止，没有通过其他浏览器、脚本或接口绕过来取得该下载文件。**浏览器实际下载验收未通过**，不能由接口检查推定为通过。

## 构建与数据核对

- 最终常规测试：84项，77通过，0失败，7项显式真实服务测试默认跳过；跳过不计为通过。
- Vue/服务端TypeScript、Vite及BFF构建通过；保留两项已有静态/动态混合导入提示，不影响功能。
- 依赖修复固定 `@fastify/static@10.1.10`、`pdfjs-dist@6.2.108`；`yauzl@3.4.0`。本轮 npm audit 汇总0漏洞。PDF销毁接口按新版loadingTask适配。
- 5项导入安全检查、全部包重封装成员哈希、四原包哈希、服务端计数及可重复运行校验通过，详情见[导入记录](benchmark-import-2026-11-08.md)。
- 四真实仓库的模板/元数据/范围细化只修改 `.oxenweb` 配置，原始JSONL、ZIP、清单字节一致，文件与条目人工赋值均为0，详见[真实服务验证](benchmark-template-validation-2026-11-08.md)。
- 64MiB JSONL源文件结构化差异有26MiB完整比较及超限拒绝回归；固定版本标签/导出使用提交元信息解析，不触发大文件整份diff。

开发热重启期间出现过一次代理读取500，重读后恢复；不把该次读取记为成功，也不把开发进程重启与数据版本冲突混淆。

## 当前尚未实现的扩展

- 通用的Web ZIP批量导入向导：本轮四包使用固定来源/哈希的受控脚本；现有Web入口为JSONL导入及工作区单文件上传。
- 组织级自定义模板另存/发布与权限：当前是六套预设，应用后可在各数据集独立增删改列、选项和层级。
- 任务分配、双人独立复核、仲裁权限和审核人签署：审核状态目前是普通版本化标签字段。
- 敏感字符跨度、多轮消息/每个工具步骤的细粒度标注：本版以一条记录/一个案例/一个Skill包为标注单位。
- 标签的全表检索和直接合并源记录的JSONL导出：当前页审核筛选与固定版本标签JSON快照已实现，源字段及标签空间保持分离。

原生Oxen权限和默认分支只读、有限规则/模型只读计划而非任意SQL、独立本地MR/标签/元数据，是已记录的能力边界。SaaS非空分支比较及部分提交摘要的上游错误仍未改写为通过；原生仓库重命名/删除未实现。详见[完整性审计](completion-audit-2026-11-08.md)。
