# 数据集管理平台使用说明

更新日期：2026-11-10。面向数据集负责人、协作者和下载使用者。

本平台用于管理数据集项目、提交与分支、项目说明、访问权限和当前发布。样本业务管理可在团队的ES系统中完成，再把整理好的数据集导入本平台保存和交付。

**每个项目只保留一个已发布版本。发布新版会移除上一版的发布记录和文件，旧下载、分享链接随之失效。项目的分支与提交历史仍然保留。**

## 1. 进入平台

访问管理员提供的平台地址。本机默认地址为 <http://localhost:3001>。

1. 点击右上角身份入口或“登录或切换身份”。
2. 使用管理员分配的个人访问令牌登录。
3. 登录后在“项目”中选择数据集。

本机开发环境可能提供“使用本机所有者身份”；团队访问时按管理员分配的身份使用。看不到某个项目或按钮，通常是该身份未获授权，请联系项目管理员。

每人使用自己的令牌。令牌签发时请及时保存，完整值不会在列表中反复展示；不要转发自己的管理员令牌。

## 2. 找到或建立数据集

项目列表支持按名称、简介和标签搜索，并可筛选命名空间、访问范围和项目标签。默认按最近修改时间排序。项目卡片显示样本数、总大小和项目标签。

|场景|操作|
|---|---|
|新建空项目|在项目列表点击“新建项目”，填写项目名称和简介，确认访问范围后创建|
|导入已有数据集|在项目列表点击“导入数据集”，选择文件并按预览结果核对数据及附件映射|
|向项目追加内容|进入项目→“数据编辑”→选择目标分支→“导入样本”|
|少量手动补充|在“数据编辑”中使用“添加样本”，或复制已有条目后修改|

导入JSONL、CSV、TSV或ZIP时，先核对预览中的条目数、字段、标识字段和附件路径，再填写提交说明并“确认导入并提交”。校验失败时按错误提示调整文件或映射，不要反复提交同一批次。

ZIP中的Skill包作为数据附件保存，不运行包内脚本。网页ZIP导入当前限制为64MiB，解压后总大小、文件数量及路径也会校验；超限时按界面提示拆分或联系管理员。

## 3. 认识项目页面

|入口|用途|
|---|---|
|概览|阅读数据集README、查看项目标签和当前发布|
|数据编辑|浏览当前分支的数据，做必要的内容校对或标注，暂存后统一提交|
|任务与复核|团队使用平台内协作时分配、提交和复核任务|
|版本与合并|查看提交与差异，创建分支、合并修改，必要时从历史提交恢复内容|
|Releases|准备候选、检查变更、发布和下载当前数据集|
|设置|维护项目简介、显示名称、标签、字段规则、权限及项目移除操作|

顶部的分支选择器决定当前查看的内容。需要查历史内容时使用“版本与合并”；这里的提交记录与Release发布包是两件事。

## 4. 项目说明、分支与修改

### 维护README和项目标签

在“概览”点击“编辑说明”，修改README，核对差异后提交。README用于说明数据集用途、来源、字段含义、使用条件和已知限制，也会放入发布包。

项目标题下方可以查看或“编辑标签”；项目标签在各分支间共享。标签的维度和选项由授权维护者统一管理，普通使用者只选择现有选项。

显示名称与简介在“设置”中维护。显示名称用于界面呈现，不等于修改项目的访问地址。

### 少量内容修改

1. 在目标分支进入“数据编辑”。
2. 双击单元格编辑。文本直接输入，有限选项按列表选择，布尔值勾选或取消。
3. 点击序号查看样本详情；普通单元格可选择文字复制。切换序号会直接更新详情。
4. 多项修改先加入自己的草稿，检查后填写提交说明，统一“提交到分支”。

**暂存或保存草稿不等于提交，提交也不等于发布。** 只有提交到分支的内容才会进入后续发布检查；未提交的私人草稿不会打进发布包。

本轮未提交修改会以红色提示，明确提交后本轮显示绿色；重新加载后不再保留本轮颜色。颜色用于帮助核对当前操作，不替代提交历史。

### 调整表格

- 拖动列头手柄改变顺序，拖动右侧分隔条调整宽度。
- 点击“保存我的表格布局”保留个人布局；这不会修改样本或生成提交。
- 点击表头排序，使用筛选缩小范围；批量修改前核对选中的条目与数量。
- 字段“是否展示”影响表格列，“是否导出”影响发布包和工作快照；隐藏列并不限制别人读取数据。

### 多人协作与合并

需要隔离修改时，为不同人员或任务建立工作分支。各自在自己的分支提交，再通过“版本与合并”核对差异并合入主分支。合并前如提示冲突，先处理冲突，不要覆盖他人的修改。

分支是一条版本路线；“高级工具”中的工作区是待提交内容的临时工作位置。工作区与分支不是同一概念，日常少量校对可直接使用“数据编辑”的草稿和统一提交。

## 5. 发布当前数据集

### 发布前检查

确认内容已经提交，并合入项目主线；检查README、导出字段和接收对象。发布包包含所选提交中的完整数据集，**不会根据quality、purposes、visibility等业务字段筛除条目或自动分包**。

在“设置”→“样本字段”中：

|设置|作用|
|---|---|
|是否展示|决定该列是否出现在数据编辑表格|
|是否导出|决定该源字段是否写入发布包和工作快照|

这两个开关相互独立。访问权限由管理员配置，不能靠把字段或条目写成“隐藏”来代替权限。

### 创建和发布

1. 进入项目的“Releases”，点击“创建 Release”。
2. 填写版本号、来源分支或提交、版本标题。
3. 等待“数据与变更检查”完成，核对条目数、附件数、导出字段及比较基线。
4. 阅读自动生成的版本说明，可直接修改。需要重新使用系统计算的文本时，点击“重新采用自动说明”。
5. 点击“保存发布候选”，再“校验并打包”。打包期间可查看排队或执行状态。
6. 就绪后点击“核对并发布”，再次核对即将替换的当前版本和接收对象，确认“正式发布”。

发布成功后，这一版自动成为唯一“当前发布”，上一版的发布记录、文件、下载和分享链接会被移除。无需另设最新版本。**旧链接不会自动变成新版本的链接**，需要重新发送当前版的下载地址。

“待发布候选”尚未正式对外交付。保存候选或打包失败不会替换当前发布，可先修正再检查。

### 自动版本说明

系统比较替换前的当前版本，生成样本、人工标注、附件、字段定义、README及仓库文件的变化统计，并列出提交摘要。首个完整发布会显示首次发布说明。

比较基线在候选中明确显示。如果其他人员先发布了新版，原候选可能提示基线变化：点击“编辑发布候选”，重新检查并核对说明后再保存和发布。已经输入的人工说明会保留，不会被静默覆盖。

### 撤回

“撤回”会移除当前发布及其文件，关闭下载与分享链接，项目随后暂无当前发布。需要再次交付时，从仍保留的数据提交创建新的Release；无法恢复旧发布链接。

## 6. 下载与分享

在“Releases”的“当前发布”中下载数据集ZIP。旁边的manifest为数量、固定提交和校验信息，可用于核对交付内容。

|包内文件|用途|
|---|---|
|README.md|数据集使用说明|
|RELEASE_NOTES.md|本版变更说明，采用发布时最终确认的文本|
|samples.jsonl|完整条目，按导出字段配置生成|
|dataset.json、schema.json、labels.json|数据集、字段及标签定义与映射|
|attachments/|条目引用的附件；Skill附件仍为压缩包|
|manifest.json、checksums.sha256|固定版本信息与文件校验|

samples.jsonl每行包含稳定标识`sample_id`、源字段`data`、人工标签`annotations`及其状态等信息。向外部系统使用时，从`data`读取源字段；人工标签及复核状态分别读取，不要把“未复核”当作已审核答案。平台记录的最后操作人和系统修改时间不作为源字段导出。

有分享权限时，使用“管理下载链接”为当前资产生成有期限的链接，并可撤销。新版本发布、当前版本撤回、链接到期或权限撤销后，旧链接失效。下载使用者不需要因此获得整个项目的编辑权限。

### 工作快照

“导出工作快照”用于内部核对已提交的完整数据集，不是正式发布，也不代表专家确认。快照不含未提交草稿，按字段导出配置打包，仅创建者及获准身份可访问，不提供公开分享链接。

新发布替换的是已发布Release，不会清空你当前的私人草稿或待发布候选。

## 7. 权限和日常维护

|职责|常见操作|
|---|---|
|下载使用者|获取当前发布包或管理员给出的有效链接|
|编辑协作者|在授权分支维护内容并提交|
|数据集负责人|组织内容、合并、检查和发布当前版本|
|项目管理员|维护项目成员、权限和项目设置|
|实例管理员|管理全局访问、字段／标签目录、操作日志和服务状态|

管理员从“访问管理”按项目和角色发放权限；每个人可在身份入口的“我的访问令牌”查看或撤销自己的令牌。不同项目、受限源数据和导出的权限可能不同，以实际按钮及管理员授权为准。

全局“操作日志”用于查看项目创建、移除、发布和权限变更；普通使用者可通过“操作核对”查看自己获准查看的操作结果。

移除项目在“设置”中进行，需要相应权限和项目名称确认。项目移除、撤回发布、删除旧发布资产是不同操作；先确认当前操作对象，避免把数据项目与下载包混淆。

## 8. 常见问题

|情况|建议处理|
|---|---|
|修改未出现在发布检查中|先确认修改已提交到正确分支，并已合入主线；私人草稿不会自动发布|
|提示分支或比较基线已变化|保留输入，重新检查版本与差异；不要反复提交同一份过期表单|
|提示存在私人草稿|先提交或按界面提示处理草稿，再导入或维护其他配置；切换页面前确认保存状态|
|保存成功但页面刷新失败|先核对已有操作结果或刷新列表，避免直接创建第二份重复候选|
|提示操作结果未知|保留页面信息，到“操作核对”确认；不要连续点击发布、提交或导入|
|打包显示排队或繁忙|等待当前任务结束再操作；不要通过重复创建候选来绕过排队|
|显示旧文件清理未完成|新版本与旧链接失效状态分别以页面为准，联系管理员处理清理；无需重复发布同一版|
|旧下载／分享链接打不开|可能已被新版替换、撤回、撤销或到期，向负责人获取当前版本链接|
|字段没有导出|检查项目字段“是否导出”；“是否展示”不会自动改变导出设置|
|看不到项目或管理入口|核对登录身份和项目授权，联系管理员；不要交换他人的管理员令牌|

部署、环境安装和服务恢复请由管理员参阅[入门与运行文档](getting-started.md)及[运维手册](operations-runbook.md)。
