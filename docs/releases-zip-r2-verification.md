此记录描述本项目的 Web/BFF 扩展，不代表 Oxen SaaS 原生 Release/tag 契约，也没有修改官方 Oxen server、OpenAPI 或存储内核。页面布局沿用既有深色设计 tokens；Releases 和数据包流程来自已确认的 R2 方案。

## Release 与下载语义

- 草稿固定 commit；草稿版本号可在项目内保持唯一的前提下调整。草稿/失败/待发布候选可显式重建；主分支前进不会改变候选。正式候选必须属于当前配置主分支可核对的已合并历史。
- 排队 → 构建 → 待发布核对 → 显式发布；失败保留原因。版本记录、构建资产与资产 SHA-256 持久保存；重启中的未完成构建标记失败，需明确重试。版本记录变更采用 revision 校验及原子文件替换。
- 正式版和预发布都校验独立复核；预发布不能成为最新稳定版。最新稳定版是显式管理的指针，不按版本字符串猜测。构建与发布再次检查权限和审核结果；审核证据发生变化时必须重建候选。
- 已发布版本号、源提交、资产不能覆盖。补充说明作为独立勘误追加，保留身份、时间与审计，原包及原说明不变。上版差异摘要以实际已发布包为基准，包括样本、行标签、数据集/文件标签、片段/步骤、附件、规范及 README。
- 工作快照单独标记未发布、未审核，允许完整导出已提交但尚未审核的数据；包含所有原意见，分歧值不假装成为采纳结果。只开放给创建者及实例所有者，不包含浏览器未保存草稿。
- 正式 `samples.jsonl` 分开 `sample_id`、原记录 `data`、采纳 `annotations`、明确采纳的 `fine_annotations` 和附件映射；源真值不被人工判断覆盖。片段位置使用 Unicode 码点 `[start,end)`，字段摘要使用本项目排序对象键后的 JSON 序列化 SHA-256。
- 下载前核对实际资产字节、长度和 SHA-256，返回 attachment、no-store、nosniff 等响应头。损坏或撤回不继续发放。已撤回仅关闭该 Release 的资产和分享，有项目导出权限者仍可另导出工作快照。
- 分享令牌只在创建时显示一次，持久化仅保存摘要；限定固定发布版本和完整 ZIP，有效期最多 30 天，可撤销。每次访问还检查创建者当前分享能力和版本状态。不自动公开项目、开放网络或把 127.0.0.1 变成外部可达地址。撤销不收回已下载副本。

## 完整包与再导入

标准包格式为 `oxen-web-dataset` v2，包含 README、dataset.json、samples.jsonl、schema.json、labels.json、CHANGELOG、附件、来源证据和 checksums.sha256；校验清单覆盖除自身外的每个成员，外部资产元数据另保存整个包的 SHA-256。标准包不要求安装 Oxen 即可读取。

规范保存完整维度、选项、释义、模板引用和版本。labels.json 保留三级标签、所有执行人原意见、片段/步骤及审核证据。正式包使用明确采纳结果，工作快照保留未审核及冲突标识。兼容旧双 hash 路径时，被新的单 hash 标注覆盖的旧记录以 supersededRecords 单独保留，不重新当作活动意见。原始归档为显式可选项，默认只带来源清单；勾选后按来源清单查找固定归档、核对摘要，并记录输出映射。

通用导入是“读取识别 → 用户映射 → 校验预览 → 确认提交”：支持 JSONL/NDJSON、CSV/TSV、每个 Skill 目录一个 ZIP、每个既有 ZIP 一个样本及本项目标准包。身份字段、附件路径字段可明确选择；不抓取 URL、不猜测安全判断。生成身份时说明采用原包 SHA、成员路径和位置，源业务字段不覆盖；选择身份字段时重复或空身份拒绝提交。

导入保留原包 SHA 与字节，来源映射和证据随同一次 DatasetService workspace 提交。标准包校验每个成员 SHA、样本数量、规范/标签一致性及附件引用；保留显式 rowId，并映射规范入口改变后的文件级/条目级标签。外部片段、步骤和审核证据作为 provenance 保存，不能冒充本机独立审核；后续导出继续携带这些来源记录。

新建项目主路径与已有空项目均可使用。已有 descriptor/bundle-manifest 的托管数据集明确 409 拒绝替换，不能通过重新初始化暗改旧基线、遗留覆盖记录或身份。导入规范定义还需组织规范权限，单有数据编辑权不构成绕过标签治理的通道。

## 容量与安全边界

| 对象 | 限制 |
| --- | --- |
| 通用上传与标准导出 ZIP | 64 MiB；超限全量失败，不截断或声称成功 |
| 通用导入 | 10,000 条目、声明/实际展开 256 MiB、单条目 64 MiB、压缩比 1,000、ZIP 读取 30 秒；映射最多 100,000 样本 |
| ZIP 比较 | 每侧 25 MiB、5,000 条目、实际展开 100 MiB、单条目 10 MiB；每侧读取 20 秒，最多两个比较并行 |
| 文本差异 | 每侧 UTF-8 256 KiB、合计 10,000 行；精细对齐最多 1,000,000 个单元，超出改为明确的完整替换区展示 |
| 导入预览 | 15 分钟、绑定创建者；一次识别任务，缓存有内存预算；关闭/替换预览可主动释放 |
| 构建与下载 | 构建串行、队列最多 8 项，构建阶段协作检查 120 秒预算；底层请求有自身超时。最多 4 个资产下载并行 |

ZIP 使用中心目录、严格路径和条目大小校验，实际读取再次限制大小并验证 CRC。拒绝穿越、绝对路径、反斜杠、重复/歧义路径、符号链接、特殊文件、加密和不支持压缩方法。成员仅在受限内存流读取，不解压落盘、安装 Skill、运行脚本或访问包内 URL。

ZIP 差异分别显示包字节 SHA 与成员实际内容 SHA：按路径判断增删改，唯一等内容的删除/新增仅提示疑似移动；权限变化单列。二进制和嵌套 ZIP 不递归处理，只比较哈希与大小；无法完整处理返回失败，不能写成“无差异”。这些校验不是恶意代码检测、来源真实性证明或无害证明。

## 验证记录与待核对项

专项命令：`npx tsx --test apps/server/test/releases.test.ts apps/server/test/archive.test.ts`。本轮已实际通过 22 项、0 失败、0 跳过，包括：

- 失败构建／文件系统写入失败可显式重试，队列继续推进；重启中的 queued/building 记录转 failed，清理失去引用的生成资产，已发布资产保持可用。清理只处理自身 UUID 普通文件，不递归或跟随目录链接；文件系统仍拒绝删除时保留现场，后续启动再尝试。
- 发布状态、固定主线提交、版本唯一、预发布/最新稳定、勘误不改资产、审核证据变化拒绝旧候选。
- 完整包逐成员校验、资产损坏阻断、实际 HTTP 下载头与字节；分享到期、撤销和创建者权限撤销。
- 根 createApp HTTP 上传大于 12 MiB 的合成 ZIP，经映射提交到新私有项目并核对原归档 SHA。
- 实际 DatasetService 的完整包再导入：源记录、稳定 ID、三级标签、附件字节、fine 来源证据保留；拒绝托管目标替换且提交不变化。
- 64 MiB 全量拒绝、原始归档默认不含/显式包含、工作快照分歧、实际成员哈希/文本差异、ZIP 损坏和超限。

当前类型检查通过；本记录不把接口测试当作浏览器验收。完整构建由主线程收口。真实浏览器下载、键盘/窄屏、正式多人任务→复核→合并→Release、四个真实库完整工作快照，以及外部可达部署的分享访问由主线程单独记录；没有因此给真实样本自动填写人工判断或审核结论，也未在本记录中保存真实样本或下载令牌。
