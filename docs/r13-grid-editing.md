# R13 表格展示与人工标签编辑

本地Web扩展，2026-11-09。复用冻结UI04/05/06的工作台与草稿操作顺序，没有新增SaaS观察；不修改Oxen官方服务端、内核或固定OpenAPI。真实样本分层仅设计待确认，本模块没有读取、分类或修改真实benchmark。

## 宽表与项目展示配置

原权重算法只在剩余视口宽度中分配空间。当固定列和系统列已占满视口时，正文权重列会压到48px。现在权重空间至少为这些列的自然宽度之和，再按权重分配；固定像素值不被拉伸或压缩，超出视口的完整表格在原容器中水平滚动。视口是可填充空间，不是表格宽度上限。工作台、表格容器仍限制在页面布局内，防止整个文档出现水平溢出。

源字段`visible`未提供或true默认可展示，false是项目层面的表格显示规则。实际表格和“列”菜单都使用同一规则，旧私有列选择、显示全部、首条新增及新字段不能把项目隐藏字段重新显示。个人列选择仍保留其原意，负责人重新启用项目展示后遵循之前的个人选择和项目排序。字段详情、完整源记录、检索与`export`配置保持独立；隐藏列不是数据权限或导出脱敏。

## 人工标签编辑修复

根因是此前改为序号单击打开详情后，“人工标签”单元格只剩展示用span，没有编辑事件。现提供双击单元格和可键盘访问的“编辑”按钮，打开独立的“样本人工标签”对话框，不依赖详情抽屉。

- 沿用当前模板的单选、多选与文本控件，不在样本编辑中创建或维护标签维度。
- 单次改动进入当前操作者已有的pending assign操作，继续按原私有草稿、diff和明确提交处理；不逐单元格提交，不改源内容或别人的意见。
- 初始与异步选择后都核对身份能力、任务行范围、历史只读、已删除及撤销新增状态；未授权按钮disabled，服务端仍是最终授权依据。
- 已有raw正文输入无法通过校验时，不跳走到另一条标签编辑。对话框目标、输入操作与权限恢复沿用检查点保护；退出对话框不丢掉已暂存的标签，键盘焦点回到原条目编辑按钮。
- 清空null、空文本或空多选后不再显示伪标签chip；不确定等明确结论继续显示。表头说明显示的是当前身份的“我的标注”，其他意见仍在详情中独立查看。
