# R17 可视化表格布局、批量编辑与四维候选

日期：2026-11-09，Asia/Shanghai。用户直接授权本轮实现；不修改官方 Oxen 0.67.0、内核或固定 OpenAPI。四类真实样本只作本机只读候选分析，不代为分类、复核或发布。

## 交互与保存边界

|位置|当前行为|保存与保护|
|---|---|---|
|数据编辑列头手柄|鼠标拖动改变列顺序；Alt＋左右键也可调整|源字段、人工标签、时间与操作人均支持；选择框和序号固定；默认人工标签在可见 id 后|
|列头右侧分隔条|拖动调整像素宽度，键盘方向键及 Shift 支持微调；双击恢复该列默认|72–1200px，初始自然宽度最高500px；表格可超出视口并内部横向滚动，不再按权重分配|
|布局工具栏|“保存我的表格布局”“撤销布局调整”“恢复默认布局”|按人员＋项目＋分支独立保存；恢复默认也需明确保存；不会修改样本、私有草稿或创建分支提交|
|设置→样本字段|保留类型、选项、显示名、帮助、颜色、展示／导出及项目默认顺序|删除自动适配按钮、接口和算法，以及固定宽度／权重配置控件；旧元数据宽度只作为不解释的历史值保留，当前布局不读取|
|全局滚动条|纵横滚动条统一16px、滑块最短32px及悬停反馈|使用共享设计 token；操作系统覆盖滚动条的表现仍由浏览器决定|
|选中样本→批量编辑|选择字段／本人标签、修改方式、预览，再勾选核对加入草稿|沿用私有保存→差异核对→一次明确提交；不按行自动提交|

布局是本地 BFF 扩展 `dataset/ui-state` 的 `table-layout` 类型，不是 Oxen 样本字段或上游接口。服务端校验版本、唯一列键、整数宽度和520项上限；键命名空间避免源字段与系统列冲突。读取项目权限仍必需，只有本人可访问自己的状态；CAS 冲突保留本地调整并要求显式核对，不静默覆盖其他窗口。

源字段隐藏／暂时不存在时保留个人偏好，但不重新打开项目禁止展示的列。字段设置原始输入检查点移除旧列宽控件数据并保留其他未完成输入；历史版本、备份中的字段 JSON 仍可读，不重写历史。

批量编辑细则见[独立说明](r17-bulk-editing.md)：单选设置／清除，多选增加／移除／替换／清空；布尔、文本、数字按现有约束编辑。未提供、null、空集合和清除本人意见分别处理；不会给原来缺失的值凭空创建空数组。原始身份、来源与源真值受保护，其他人员意见、未选择维度、片段和步骤保持。内容变更导致旧片段锚点失效时拒绝并保留输入，需重新定位，不能自动丢弃证据。

跨页选择按固定 commit 和草稿 ID／revision 读取全部已选身份；读取失败阻止整批，不能静默缩为当前页。最多选择500条，合并后累计操作超过500也会阻止加入；已有修改先合并后计算。预览区列出实际改变、同值和权限跳过范围。提交仍由后端重验权限、任务、CAS 和字段规范。金标值不等于通过独立复核，visibility 取值不授予隐藏或分享权限。

完整数量、比例、当前源提交、四维交叉表、同源关系与未解决风险见[候选报告](research/real-dataset-four-dim-candidates-r17.md)和[机器聚合](research/real-dataset-four-dim-candidates-r17-summary.json)。固定读取6,719条，旧提示词别名2,000条不重复计数；源正文、真值、身份和附件与 R14 关系证据核对一致。提示词有1条用户后续四维修改，保留为原值观察，不被分析覆盖。

严格实体／关键成员候选为 train4,807／dev893／test865／暂缓154；金标优先复核目标657，当前有效金标0。隐藏431只是候选目标：敏感仅3条，Skill73条中正常仅1条，不能当作有代表性的独立验收集。近60/20/20对照仍有198个敏感实体指纹、24个Skill关键成员指纹跨 split，不建议据此批准隐藏集。154条配对不全、跨库谱系、公共样板与预训练曝光等风险继续保留。

成员清单、隐藏索引、指纹、密钥与种子仅存 Git 忽略的 `.data/r17-four-dim-candidates/`。公开文档只含聚合。两个成功切点的同种子12份成员文件摘要一致；中间控制切点变化曾导致检查停止，未记作通过。用户已有草稿、Release 草案及策略不由本轮清理或覆盖。
