# 样本字段与表格编辑设计

日期：2026-11-08。本文记录本地 Web/BFF 扩展设计，不是新的 Oxen SaaS 观察。冻结 SaaS 的 Add column、类型和工作区提交交互仍见既有知识库 UI06；不复制托管前端或 CSGHub 源码，不修改官方 Oxen server/内核。

## 官方参考与采用范围

- [AG Grid：Vue Cell Editing](https://www.ag-grid.com/vue-data-grid/cell-editing/)按列数据类型选择编辑器，并支持按条件限制编辑。本项目沿用已有 Vue 表格，不引入新的网格依赖；采用文本、数字、布尔和有限选项各自匹配控件的做法。
- [JSON Schema：type](https://json-schema.org/understanding-json-schema/reference/type)区分字符串、数字、整数、布尔、数组和对象；[enum](https://json-schema.org/understanding-json-schema/reference/enum)表达有限值域。本地配置采用这些清晰的类型含义，不声称实现完整 JSON Schema 标准。
- [JSON Schema：object](https://json-schema.org/understanding-json-schema/reference/object)区分属性不存在与值为 null。因此未填写、null、false、0、空字符串和空数组不能用真假值判断合并。

## 用户交互

项目设置中的样本字段配置维护字段 ID、显示名称、帮助说明、值类型、是否允许空值、是否必填及有限选项。已有源字段不能借此重命名或批量转换；新增列先成为描述中的逻辑列，直到用户真正填写才进入条目内容。数据编辑双击按配置显示控件：自由文本、数值输入、布尔勾选、单选列表和数组多选。未配置的字段继续按实际值编辑，结构化对象保留 JSON 编辑能力。身份、来源证据及既有源真值继续只读。

有限选项需要提前配置，前后端使用相同类型和值域约束。保存配置前检查完整已有数据，冲突只返回数量与字段/稳定行 ID 摘要，不将真实样本正文写入日志。规则变更版本化保存于数据集描述，样本正文原件不改写。本人未提交草稿或活动标注任务需要先处理，规则变化不能静默改变草稿或复核语义。

当前页面会话中，未提交的有效修改显示红色；保存私有草稿仍是未提交。成功提交后本轮变更显示绿色，提交失败不转绿。恢复原值取消相应修改，后续再次编辑以未提交状态优先。刷新或重新进入后不保留绿色会话标记；文字、状态标识和前后值提示作为颜色的补充。

## 标签管理与卡片

模板引用已发布维度的确定版本，保障历史赋值的含义。该版本关系保留在后端；主表单简化版本操作，将版本细节移入高级设置，更新已有引用需明确操作。

项目关键词和模板维度是两类不同数据，但卡片上的标签都应提供一致的点击入口。关键词以独立关键词筛选处理；模板标签使用真实的组织、维度和值筛选，不把关键词伪造成模板维度。筛选不覆盖用户原有搜索输入，并支持查看及清除已选条件。

## 实现与验证位置

字段定义使用 `DatasetDescriptor.fields`，由 BFF 独立字段配置接口维护；统一校验覆盖表格、完整 JSON、新增和私有草稿提交。页面映射为项目设置字段面板、DatasetWorkbench、全局 LabelGovernanceView 与 RepositoriesView。实际测试、原生服务回执和合成浏览器截图在 R6 实施记录中单独登记，代码存在不视为验收通过。
