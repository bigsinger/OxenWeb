# R9 字段排序、表格与详情交互

日期：2026-11-08。本轮只修改本项目的 TypeScript Web/BFF 和展示配置，不修改官方 Oxen 0.67 server、内核或固定 OpenAPI。四个真实 benchmark 项目未写入。

## 已直接授权的实现

- 项目设置的“样本字段”增加拖动手柄、前后落点指示、上下移动按钮和 `Alt+↑/↓`。搜索时只重排可见槽位，隐藏字段保留；还原顺序不丢弃其他未完成字段输入。排序自动保留为私有配置输入，点击“校验并保存字段”才生成一次版本。
- `.oxenweb/dataset.json` 的字段元数据增加本地展示属性 `order`。BFF 读取、固定提交投影和 Web 可见列采用同一稳定排序；未配置字段保留自然相对顺序。系统选择列、序号与人工标签列保持各自位置；个人检查点只决定源列是否可见，不覆盖项目顺序。纯排序/列宽配置不会重新展开隐藏列或把附件哈希列全部展开，真正新逻辑列仍可自动出现。
- `order` 与 `width` 均从规则、私有草稿和复核的语义指纹剥离。纯展示更新不修改源记录、源身份、标签定义或判断；同步新 HEAD 仍遵守现有显式核对、权限和 CAS。真正的类型、选项、说明变更仍走既有保护。
- 只有序号单元格打开或切换详情。抽屉非模态覆盖表格，桌面露出的序号可直接切换下一条；正文/外部点击只隐藏抽屉，不抢焦点或选择区。关闭按钮与 Escape 把焦点还给当前序号。窄屏抽屉覆盖整屏，沿用上一条/下一条和关闭入口。
- 正文选择复制、双击行内编辑保留。未闭合 JSON 会阻止错误切行，原输入可在隐藏、重开和检查点中保留；正常选择不重取整表，也不改变底层表格宽度。
- 表头第一行显示字段 ID，第二行显示已有显示名称；项目配置优先，精确通用字典为后备，未知字段不猜别名。悬停显示已有帮助。表格正文/ID 表头为14px，别名12px，行高1.6，序号列64px，窄屏不缩回10px。尺寸使用共享 tokens。

## 实测与证据

最终全套 `npm test`：333项，326通过、0失败、7默认跳过，日志 `.data/r9-tests-final.log`。第一轮331项后，复核补修纯展示配置重新展开隐藏列的问题，并增加2项针对性回归；修复后重新跑完整测试和构建。构建包含前后端类型检查且通过，日志 `.data/r9-build-final.log`。不把默认 live skip 计为通过。

官方0.67专项只复用先前合成库 `local/r8-project-acceptance-mw7tdcfk` 的3条记录。保存 `score,text,id` 顺序后，固定提交列序一致，原始 JSONL 字节、逻辑行、稳定身份和复核指纹均不变；提交为 `d3ec343ab4cfc2f12d0331dc14d892d4`，回执 `.data/r9-native/verification.json`。没有创建或修改真实样本。

浏览器通过应用内浏览器/CUA 验证合成夹具 `local/ai-safety-ui-qa`，使用 `127.0.0.1:5173`，桌面默认视口和390×844窄屏。专门 Browser 插件未提供，使用已启用的 CUA Playwright 接口，没有另起外部 Playwright/CDP。

| 路径 | 观察结果 |
| --- | --- |
| 点击正文 → 双击正文 | 不打开详情；双击进入 `编辑 prompt`，Escape可取消 |
| 序号qa-1 → 序号qa-2 | 一次点击直接显示qa-2，抽屉不先关闭；底层表格仍1782px |
| 切行和正文交互 | QA整表查询计数3→3，没有查询/草稿提交；检查点单独持久化 |
| 非法JSON → 切其他序号 | 保持qa-1和原始未闭合输入并报错；正文隐藏后重开仍保留；取消后可正常切qa-2 |
| title上移 → 离页返回 → 保存 | 私有输入恢复，保存前字段写接口0次；保存一次后title移到uid之前，已有标题别名保留 |
| 隐藏uid → 刷新版本 | uid继续隐藏；真实新增字段仍按现有规则显示，恢复选择后位置由项目顺序决定 |
| 表头/字体 | id/标识、prompt/提示词、title/业务标题分行；score/source_kind无虚构别名，正文与表头14px |
| 窄屏 | 390px视口，文档380px无整页横向溢出；详情380px覆盖整屏，表格字体14px |

字段排序的真实鼠标拖动手势未通过当前浏览器接口自动化执行；拖放事件、过滤重排算法、上下移动与持久化已实现并分别经源码/回归/浏览器核对。不能将键盘移动冒充鼠标拖动端到端通过。未验证所有浏览器或超出当前规模的容量。
