# R4 样本选中性能、字段解释与开发期标签简化

日期：2026-11-08。用户本轮明确取消旧标签兼容要求，取代R3关于保留兼容记录的设计；Oxen历史提交本身保持原状。本轮只修改TypeScript Web/BFF和当前项目的Web元数据，不改Oxen server/内核。

## 根因及结果

数据工作台原来监听 `watch(() => [base, branch, route.query.commit, principal], reset)`。点击条目通过router.replace修改query.sample，导致route.query替换，getter返回新数组，即使四个上下文值没变化也触发reset和整表查询。因此数据已加载却反复显示加载态，草稿也可能被迫保存。

现在使用Vue独立watch sources，仅项目、分支、固定commit或身份真实变化才重置。已加载条目的选择仅更新本地selected与地址栏sample，右侧直接消费已有记录，不重取列表、不触发草稿保存；重复点击同一项直接返回。外部深链接指向其他页时才定位读取；显式搜索、筛选、分页、刷新、分支和固定版本切换仍保留原加载行为。未保存编辑仍在本地，不因切换条目丢失或串到其他条目。

字段详情采用独立组件：原ID + 有定义的显示名称 + 实际值类型，标题/Info悬停显示纯文本帮助，键盘可聚焦Info。数据集descriptor.fields配置优先于常见字段字典，未知字段不猜测，显式空串可关闭默认解释。折叠的长文本、数组和对象不提前JSON格式化。详见[源字段解释](source-field-help.md)。没有修改源键名、值或人工标签规范。

## 取消兼容数据流

当前分层模板不再复制legacy/legacyColumns，也不回退到旧混合规范。工作台、分支标签与规范采用面板移除兼容区；API不返回compatibility，不支持legacy.*检索，保存时不生成legacy-labels档案，Release不导出兼容值。治理预设列表只列七个新模板。固定旧提交仍可作为版本历史读取，不重写历史或将旧值自动提升成新判断。

四真实项目的main已各用一次元数据提交清理旧标签基线、旧规范副本及不属于活动层的意见，并将项目关键词ai-safety改为aisec。保留当前活动层的意见和样本正文覆盖；原始JSONL完整SHA逐库核对未变。当前四库只有main分支，执行前已核对。

## 验证

完整构建及前后端类型检查通过。全回归198项：191通过、0失败、7默认跳过的独立live专用测试；日志 `.data/r4-all-tests.log`。新增Vue实际响应式测试验证query对象替换不重置、上下文改变仍加载、跨页定位；字段测试覆盖明确元数据优先、未知字段、纯文本、大小写、类型、持久读取和源数据不变。标签/草稿/发布相关专项同步按新需求修改，不再将R3兼容保留当成验收条件。

- uid显示“唯一标识”；title使用显式“业务标题”覆盖默认“标题”；description显示“描述”；unmapped_field只有ID和类型。Info键盘聚焦后可见配置的tooltip，悬停使用同一纯文本说明。字段无旧兼容区。截图：[详情与帮助](evidence/r4-interactions/field-help.jpg)，全为合成数据。
