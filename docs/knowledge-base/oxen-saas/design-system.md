## 本地设计选择

以下是为可读性和一致性作出的本地实现选择，不声称是 SaaS 源码或所有像素的复制。

| Token | 值 | 用途 |
| --- | --- | --- |
| --bg | #171717 | 页面底色 |
| --surface | #1c1c1f | 数据/内容面板 |
| --surface-raised | #242426 | 浮层、控件、次级内容 |
| --line | #343438 | 边框与区域分隔 |
| --text | #f2f2f4 | 主要文字 |
| --muted | #a5a5ae | 次要说明，保持深色下可读 |
| --primary | #8b35e2 | 主操作填色 |
| --accent | #b88bf0 | 可点击文本/焦点，避免深紫小字低对比 |
| --success / --danger | #77ce9c / #f08b90 | 成功/危险语义，不能混用为装饰色 |
| --radius | 6px | 常规控件和面板 |

排版使用本机可用的 Segoe UI Variable/Segoe UI/微软雅黑回退，不额外请求第三方字体。正文以 14px 为主，数据表格为 12–13px，重要表单控件约 38px 高；更小字号只用于非关键元信息。主标题 30–32px。容器最大约 1480px，桌面边距 40px，窄屏减为 16px。

## 交互与组件规则

- 全局操作放在顶部：项目切换、项目搜索（Ctrl/Cmd K）、连接状态、身份。保留真实可访问项目列表，不放虚构容量、余额或云按钮。
- 项目标题/描述/可见性和真实统计构成统一 masthead。管理与版本入口与 SaaS 同区；提交/分支/MR 收入开发者工具。
- 文件列表默认是 SaaS 式列表，可切网格；目录树为可展开辅助，不挤占数据主区。支持该格式的查询、编辑、标注、历史携带当前文件路径与分支；从图片/PDF转到数据查询时先选择表格，不把媒体路径当成表格。分支切换保留当前文件，提交详情切分支则返回该分支历史。
- 查询完整数据与“过滤当前页”明确分开。未选文件时可浏览实际目录选择；不预填不存在的其他项目文件。
- 数据/配置表单、列表筛选、状态反馈、弹层和菜单用共享 tokens；不在 scoped CSS 中重新建立一套浅色/绿色主题。
- 动作入口使用用户任务名称。CLI、BFF、版本文件位置等实现说明放帮助/折叠详情，需要理解边界时仍可查阅。
- 禁用状态须可解释；不使用假按钮。写入沿用权限、expectedCommit/revision、固定版本和异步站内离开确认；改版不削弱它们。
- 数据表格可横向滚动、列头/行号清晰，长文本可展开；不要缩小到 8–10px 强塞所有列。弹层可关闭、能翻相邻记录。
