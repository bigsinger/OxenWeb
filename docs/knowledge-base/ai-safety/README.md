## 必须保持的语义

一个 Skill ZIP 是一个样本，对应 `data/samples.jsonl` 一行；包内成员只读展示，不能当作待安装技能。原包、逐包SHA、原 `_expected.json` 与行清单中的原真值均保留。26个嵌套ZIP作为不透明成员保存，不自动展开。

敏感数据存在不等于恶意意图；攻击输入存在不等于攻击成功。源真值、人工判定、预期行为、观察行为、审核进度、置信度分别记录。新导入数据的人工条目标注保持空白，模板不会自动给出安全判断。

R1/R2 已取代早期“在打标页自行改列”的交互：组织管理员或指定维护者在全局标签管理中另存预设、维护维度和发布不可变模板版本；项目负责人采用固定版本，标注人员只消费这些字段，缺项走反馈。模板升级必须显式执行，不能改变活动任务的规范。正文覆盖、三级人工赋值、字符片段和步骤均按稳定身份保存，保护 `expectedCommit`、权限与草稿；内容、ZIP 实际字节或规范变化会使复核失效。历史文档中的旧列管理界面仅作旧轮证据。

README 在概览，选分支后数据编辑直接显示完整样本，无需选择物理 `data/` 路径。任务在独立分支执行，复核证据随真实提交保留；正式 Releases 从通过校验的主分支固定提交构建，工作快照不提供审核背书。详见 [R1/R2 实施记录](../../implementation-r2.md)及[整合方案](../../proposals/dataset-labeling-workflow-v2.md)。

R5起，卡片、项目顶部和概览的项目标签始终读取main的一份分类，不随工作分支或历史样本视图切换；“保存标签”只提交项目元数据。样本编辑、独立意见、任务和复核仍按分支隔离，样本草稿继续显式保存与正式提交。复制样本创建新身份，不能把原人工标注或审核状态当作新条目的既有结论。

四真实项目已用新模板明确填写各自研究主题，aisec关键词与主题在卡片可见。初始化逐库只写一份项目标签文件，6719条源JSONL完整SHA不变；提交与回执见[R5验收](../../implementation-r5.md)。这些主题表达集合用途分类，不代表每条样本的恶意判断或复核状态。

来源与基线可以随样本不同而变化；不要强迫所有条目共用同一个出处、目标或技能审查建议。层级以列的 `scopes` 为准，源字段只读展示与可编辑标签要清晰分开。

## 后续如何补充

2026-11-08 已实施[R3分层方案](../../proposals/label-layers-r3.md)：组织/领域筛选、数据集与样本独立模板、分支数据集标签、卡片筛选及表格垂直居中；同时增加本机私有草稿，先保存、核对，再一次提交。[R3实施与验收](../../implementation-r3.md)保留当时的迁移、备份和21个旧合成项目清理事实。随后用户在R4明确取消开发阶段兼容要求：四真实main已清理旧标签基线及旧意见，源JSONL与truth不变，不再生成/展示/导出compatibility，也不自动把旧值转成新结论。该取消兼容的事实以[R4记录](../../implementation-r4.md)为准，当前项目标签及编辑交互以[R5记录](../../implementation-r5.md)为准；早期[模型评审](../../proposals/review-label-layers-data.md)和迁移预览只作为历史。

新增领域先检查源字段含义、唯一标识与真值约定，再设计模板。保留“未知/不确定/未审核/不适用/未赋值”的区别；没有定义就不把 positive/negative 翻成恶意/正常。

调研与验收文档只记录结构、数量、哈希、位置和合成截图。真实敏感信息、攻击提示、Skill 指令与秘密不进入知识库；不向模型或 SaaS 上传记录正文。原始数据与运行状态仅保存在被忽略的 `.data/benchmark-import/` 及本机 Oxen 中。

R5补充：同在main编辑样本时，项目标签提交后必须显式同步草稿基点；仅标签文件变化可同步，正文或规范变化拒绝。本人过期草稿仍可通过受权接口导出，浏览器落盘审批拒绝未冒充验收通过。两条恢复路径、原生回执及最终229项回归（222通过、7跳过）见[R5验收](../../implementation-r5.md)。

R7补充：检查点保存用户原始控件状态，可包含不完整JSON/选项，不能当作有效数据、已提交标注或审核通过。处理样本提交后，字段定义未变可恢复配置；定义也变则明确对照，不用旧表单自动覆盖新规则。列宽属于纯Web显示，可独立保存，不改源数据、标签语义和审核指纹；其他规范变化仍受任务与草稿保护。原生专项只操作120条合成库，原JSONL SHA保持，四真实benchmark项目本轮未修改；细节与证据见[R7验收](../../implementation-r7.md)。

R6字段约束由本地BFF维护，不能把布尔false、未提供、null和空值混成一种状态。新字段不自动填值，规则变更不能静默套用到已有草稿或活动任务。配置与样本判断分开；绿色表示提交成功，不是通过复核。实际来源、原生服务与合成界面验收见[R6记录](../../implementation-r6.md)。

R8本地扩展：导入已有数据集采用追加与身份/附件保护；Skill ZIP始终不执行。项目主题、来源、行业从模板选项消费，README与样本独立编辑；抽样列宽不外发记录。项目移除保留上游版本，属于BFF可恢复控制面。[R8验收](../../implementation-r8.md)与[开源对照](../../research/open-source-alternatives-2026-11-08.md)供后续沿用。
