## 使用与实现

- 项目设置 → 样本字段，在“是否导出”正下方增加“是否展示（数据编辑表格）”，默认勾选。取消后保存，该字段不出现在表格与个人列菜单；“显示全部字段”和旧个人检查点不能绕过项目规则。详情、检索、源值与导出保持独立。重新勾选可恢复展示，个人列偏好继续生效。
- 宽表保留固定像素和权重；权重的可用预算至少为字段自然宽度总和，防止多列挤成48px。表格总宽不受屏幕宽度上限约束，超出部分在表格容器中水平滚动；页面文档本身不横向溢出。
- “人工标签”单元格可双击，或使用单元格中的“编辑”按钮，进入独立的“样本人工标签”表单。复用现有单选、多选和文本类型、释义及更多字段；修改进入当前操作者的私有草稿，再统一提交。只点正文仍可选择复制，序号仍负责打开详情。

字段约定`visible?: boolean`，省略/true默认展示，false隐藏。没有批量迁移旧定义或补写默认true。和列宽、排序、颜色、导出开关一样，visible不改变字段语义哈希与复核指纹。配置保存后，旧样本草稿仍须明确“同步元数据版本”；CAS和正文/规则变化保护保留。标签操作再次校验身份、历史、任务范围和删除状态，只更新当前身份的独立意见，保留已有片段/步骤及他人意见。

模块细节与专项结果：[字段展示](r13-field-visibility.md)、[表格与标签](r13-grid-editing.md)。核心组件为`SampleFieldsPanel`、`DatasetWorkbench`、`DatasetLabelFields`，并调整共享字段schema、纯展示判定、列布局和检查点；未引入新的数据集业务实体。
