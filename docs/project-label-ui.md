# 项目统一标签交互

2026-11-08，用户要求的R5本地Web调整。项目分类改为读取 **main 的一份项目标签**，具体样本正文和样本标注仍按工作分支处理。这是本地产品选择，不是新增SaaS观察结论。

项目卡片、项目顶部和概览展示同一份main分类。切换工作分支、选中样本或查看历史提交不会切换项目标签。顶部有明确的“编辑标签”；没有赋值权限的人员显示“查看标签”。模板定义、字段和选项仍由组织规范维护者管理，项目面板只负责选择值。

项目标签面板使用独立的 `GET/PUT /project-labels` 接口。本地选择完成后点击“保存标签”，只保存这次项目分类修改，样本工作台的内容编辑和私有草稿由其原流程处理。面板中不再出现“提交全部草稿”。并发版本冲突、网络或权限失败保留面板输入；关闭或切换时可以保存、明确放弃或返回编辑。

没有main分支与没有标签模板分别显示：有配置权限者可前往分支管理，或跳到 `settings?branch=main` 配置项目标签模板。模板相关入口始终指向main，不跟随当前工作分支。

`aisec` 等项目关键词从固定main的项目策略读取，以虚线样式与模板维度选项区分；不会把自由关键词转换成某个维度的选项。卡片和顶部最多显示3个主要项以及+N，`aisec` 优先可见。关键词继续参与搜索，结构化筛选仍只匹配真实维度与稳定选项。

实现入口：`BranchDatasetLabels.vue`（保留旧文件名，交互已改为项目标签）、`ProjectLabelSummary.vue`、`RepositoryView.vue`、`RepositoriesView.vue`、`project-label-chips.ts`。字段说明功能继续独立维护于[源字段帮助](source-field-help.md)。
