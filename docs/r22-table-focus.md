# R22 UX05：行内编辑后的键盘位置

日期：2026-11-10，Asia/Shanghai。对应 [R21 交互审查 UX05](review-ux-r21.md) 和冻结目录 UI04/05/06。此项是已批准的本地 Web 交互修订，无新增 SaaS 观察，不改 Oxen、数据 API、权限或版本规则。

原源码在 Enter 暂存/Esc 取消后移除编辑控件，仅开始编辑时显式聚焦；焦点是否回到页面根节点属于待浏览器复核的风险，未声称此前已经实测复现。

本次变更：

- 显式暂存/取消后，等待 Vue 完成更新，再按稳定 rowId＋字段 ID 返回原单元格；单元格使用 tabindex=-1，不增加整表 Tab 停靠点，并复用 accent 焦点轮廓和 preventScroll。
- 排序重排不依赖行号/列号；行被筛掉、字段隐藏或移除时，不跳到邻行或其他列。
- 项目、分支、历史提交、表格加载代次、另一编辑请求或其他面板变化时丢弃迟到的聚焦。用户已移到其他控件时保留其焦点。
- 普通 blur、排序、导航调用的自动暂存不恢复焦点；校验失败仍留在编辑器及原始输入上。
- 开始编辑改为查找原单元格内控件，增加异步上下文保护，不再全局查找第一处编辑器。保留已有 IME isComposing 检查、双击编辑、单击正文选择/复制、仅序号打开详情。

变更位置：`DatasetWorkbench.vue`、其 CSS、`dataset-cell-focus.ts`。没有修改 `DatasetCellControl` 的输入法和键盘语义，也未添加新的编辑方式。
