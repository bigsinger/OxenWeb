## 已实现的交互与规则

|位置|行为|
|---|---|
|全局导航“标签管理”之后|新增“字段管理”。管理员及显式指定的全局字段维护者可见、可操作；组织标签维护权限不自动扩大到全实例|
|字段管理|四个稳定 ID，固定单／多选类型，配置显示名、说明、选项中文别名及颜色；可扩展用途选项。已发布选项 ID 不改名／删除，避免改变原有样本语义|
|项目采用情况|核对各项目 main（没有 main 时采用默认分支）的缺失／差异定义，明确选中并同步。目录版本和项目 HEAD 双 CAS；活动任务、本人样本草稿、非法数据等逐项目报告，不强制覆盖；四真实项目的采用脚本另检查所有身份的未完成输入|
|新建或初始化数据集|自动预置四个字段定义，不给样本推断默认取值；存在的 split 原值继续保留|
|项目设置→样本字段|四个全局字段与其他列共同列出；类型／选项／释义在此只读。删除按钮可见、禁用且有说明；排序、列宽、是否展示、是否导出可独立维护|
|样本列表行内编辑|单选／多选控件使用稳定 ID 保存，中文名称显示；选项颜色继续生效。人工标签仍独立并位于可见 id 后|
|自动列宽|仅当前勾选展示字段参与；最多随机抽样 200 条。权重依据 p85，像素下限参考表头和抽样最长行，至少 96px，自动适配最高 500px；表格内部横向滚动|
|自定义字段删除|准确输入 ID 后一次提交移除当前有效记录中的键及配置。原文件／归档／历史不改写；身份、来源、原始真值、附件引用及全局四字段受保护|
|正式 Release|四维项目要求先启用私有受限策略。按源字段独立选金标测试、开发回归、可分享全集、隐藏测试；内部及未分类不会自动共享|
|评测集合冻结|当前通过 Release 的四个固定视图及清单固定成员 ID、来源提交／内容摘要、采纳答案摘要、筛选规则版本和填写的评分规则版本；没有独立任意集合管理页面，只记录外部评分规则标识，不复制规则正文或执行评分|

自动宽度只代表本机有界抽样的估计，不声称扫描每一条长文本。超过 500px 的内容使用已有换行预览、悬停、详情／编辑器查看；手动固定宽度仍允许用户原有的更大值。撤销和恢复保留自动适配边界，隐藏列不被适配覆盖。

“是否展示”不是权限；“是否导出”是正式交付字段投影。四维字段即使不导出，其取值仍参与分组校验，不能借取消导出来绕过隐藏限制。

## 四维正式发布

|视图|选择条件|附加要求|
|---|---|---|
|金标测试 `gold`|`split=test`、`quality=gold`、`visibility=shared/public`|有效独立复核；不是把旧 gold 用途直接转成金标质量|
|开发回归 `regression`|`split=dev`、`purposes` 含 `regression`、`visibility=shared/public`|有效独立复核；历史缺陷关联由受控样本说明维护|
|可分享全集 `nonhidden-all`|完整四维值且 `visibility=shared/public`|稳定身份去重；internal 不属于“非隐藏就可外发”|
|隐藏测试 `hidden`|`split=test`、`visibility=hidden`，其他维度完整|有效独立复核，独立私有 ZIP，仅授权负责人下载；通常应另选 gold 保证质量|

固定历史版本继续使用其原有筛选规则。当前已知 family 跨 train/dev/test 会阻止新四维发布；家族、附件字节及既往曝光检查继续执行。没有推定已经完成跨四库语义级泄漏防护，R14 报告的问题仍需要处理。

`quality=gold` 是结构化质量声明，正式发布还要满足独立复核门禁；系统不会自动判断证据是否达到领域金标标准。应在最终独立复核前确定并提交 `split`、`quality`、`purposes`、`visibility`，让复核覆盖包含这些值的完整样本版本。此时填入 gold 仍只是待复核的质量声明；只有有效复核证明才能支持正式金标发布。条目的四维取值变化会改变内容哈希，复核后再调整任何一项都需重新复核，不能绕过或复用旧指纹。

评分规则目前用一个 `scoringRuleVersion` 标识记录，调用方须另外保存该标识对应的不可变规则文件、执行器与运行证据。四维视图中的金标测试要求 test、开发回归要求 dev，因此这两个固定视图在同一次四维发布中不重叠；一条样本仍可同时属于对应子集和可分享全集。

全局采用在控制面留下不可随仓库回滚删除的治理标记。恢复旧描述文件不会使旧全量包分享重新开放；负责人仍可检查历史包。文件、API 和历史没有完整行级 ACL，因此隐藏应优先采用独立私有项目；当前算法／QA 仍只接收授权的发布包。分享链接是限期可撤销的持有者授权，不能当作指定自然人账号绑定；隐藏 ZIP 不生成外部分享链接。
