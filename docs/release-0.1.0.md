2026-11-08，首个工程源码版本。Vue 3 + TypeScript Web 与 Node.js BFF 连接固定官方 Oxen 0.67.0；数据浏览、样本编辑、标签治理、任务复核、版本合并和数据集 Releases 在同一版本交付。

- 项目设置：显示名和简介、结构化领域标签、两步完整名称确认、管理员可恢复移除与回收站。
- 概览：README 在线编辑、预览、变更核对与历史；未初始化项目也可先写说明。
- 数据编辑：空项目引导、手动新增/复制、CSV/JSONL/受管 ZIP 初始与追加导入、全表排序、完整宽度及覆盖抽屉。
- 字段：类型与有限选项、固定/权重列宽、随机样本自动评估；输入和私有草稿与明确提交分开。
- 协作：项目与样本模板分层、独立标注、任务与双人复核、字符/步骤、固定版本发布与导出。
